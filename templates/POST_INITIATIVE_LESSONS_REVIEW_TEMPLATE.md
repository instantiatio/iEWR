# Наблюдения и полезные lessons — optional result

Применять только для current requested/useful review, внутри данного scope.
Завершение задачи, «Mission Complete!» или наличие шаблона не запускают review.
Material failures, deviations и effects фиксировать сразу у X/E/direct owner,
не откладывать до lessons. Этот документ — derived view, не новый writer.

## Полезные выводы

Для каждого полезного вывода: bounded context, observation, explanation/hypothesis,
countercase, consequence, confidence/evidence limit, direct owner, affected use
и reopen observation. Positive outcome не превращать в qualified common pattern.
Не требовать отдельной pattern/antipattern card для каждого наблюдения.
