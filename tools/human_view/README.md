# Human Views для чтения

Пять композиций одного автономного HTML: Situation, Change, Plan, Review, Result.
Выбор достаточного разговора или файла — по [I Human Views](../../modules/interaction/HUMAN_VIEWS.md).
Решение с отдельным ответом — прежний [Decision View](../decision_view/README.md).
Новый helper не принимает ответы и не исполняет действий.

## Начало

Из корня распакованного iEWR, Python 3.10+ без дополнительных библиотек:

```sh
python -X utf8 -B tools/human_view/build.py tools/human_view/examples/situation.json project/handoff/situation-1.html --root .
```

В `examples/` есть `situation.json`, `change.json`, `plan.json`, `review.json`,
`result.json` и связанное учебное `observations.json`. Каждый пример — отдельный
use одного условного импорта; создавать все пять для одного реального handoff
не следует. Подставить нужный вход и новый путь результата. Каталог результата
должен существовать. Открыть HTML как файл; сеть, JS и server не нужны.
Раскрытие деталей работает стандартными средствами браузера, включая клавиатуру.

Для текстового возврата без создания файла добавить `--text`: вывод содержит
все слои, включая свёрнутые. Путь результата нужен для расчёта относительных
ссылок. Старый файл может существовать при `--text`, но не при записи HTML.

## Явная проекция

Schema 1 имеет ровно поля ниже; неизвестные/повторные поля и неверные типы —
ошибка. Пустые placeholders не заполняются содержанием автоматически.

| Поле | Содержание |
| --- | --- |
| `schema`, `id`, `revision`, `kind` | `1`, стабильный предмет, редакция, один из пяти lowercase kinds |
| `title`, `subject`, `recipient`, `summary` | Заголовок, точный предмет, получатель/use, основной вывод |
| `status` | `{label, tone}`; tone `neutral`, `attention`, `blocking`, `success`; supplied смысл с текстовой меткой, не автоматическая оценка |
| `asOf`, `scope` | ISO datetime с timezone и выбранный охват |
| `coverage` | `{sources: [ref], omissions: [string]}`; пустые sources дают видимый пробел, пустые omissions не доказывают полноты |
| `limits` | Всегда видимые существенные условия/риски/неизвестности; пустой список — утверждение составителя, требующее content review |
| `attention` | `{mode: GLANCE|STANDARD|DEEP, reason: string}`; причина выбора, без обещания времени |
| `sections` | Секции `{id,title,level,format,content}` |
| `materials` | Список refs только для полезных дополнений |
| `refreshWhen`, `next` | Когда сверить основания и создать новую редакцию; что требуется от человека/что уже разрешено/что завершено |
| `synthetic` | Boolean; true явно помечает учебный пример |

Обязательная основная секция всегда `level:core`: `state` для Situation,
`delta` для Change, `course` для Plan, `review` для Review, `outcome` для Result.
Это минимальные composition anchors, не полнота domain semantics. Change `delta`
использует `format:change`; назвать сравниваемые редакции/охват в содержании.
Остальные секции имеют уникальный ASCII id, осмысленный заголовок и один уровень:
`core` всегда видим, `standard` открыт в STANDARD/DEEP, `deep` открыт в DEEP.
В любом режиме все детали можно раскрыть; содержание не обрезается.

| `format` | `content` |
| --- | --- |
| `text` | Непустая строка, отображаемая как текст |
| `list` | Непустой список строк |
| `table` | `{columns:[string], rows:[[string]]}`, одинаковое число ячеек |
| `change` | Непустой список `{subject,before,after,consequence}` |

Нет raw HTML, автоматических графиков или SVG sanitizer. Готовая проверенная
схема — material; существующий ER helper создаёт SVG/HTML из явной модели.
HTML экранирует текст и запрещает scripts/connections через CSP; это не делает
произвольный связанный HTML безопасным. Пригодность материала проверяет автор.

## Ссылки, snapshots и ограничения

Ref имеет ровно `{label, revision, purpose, path, sha256}`. Первые три поля —
понятное имя, точная редакция и вклад. `path` — относительный путь от JSON внутри
выбранного root; `sha256` — ожидаемый lowercase SHA-256. Для доступного файла
hash обязателен; mismatch останавливает сборку. `path:null` — источник не
предоставлен локально; `sha256:null` допустим для недоступного источника.
Отсутствие файла показывается как видимый пробел; это не отрицательный факт.
URL, абсолютные пути, query/fragment, %-кодирование, symlinks/reparse и Windows
alternate streams не поддерживаются. Внешний источник обозначается именем с
`path:null`; загрузки нет. ZIP показывает имя/размер перед явным скачиванием.

Input до 1 MiB, source до 32 MiB, до 30 sections, до 100 элементов в списке,
до 12 столбцов, строка до 12000 символов. Это пределы обработки, не обещание
читаемости максимального входа. Данные/порядок/значимость готовит caller.

Выход — новый `.html` в `project/handoff/` или `project/artifacts/`. Запись
exclusive и readback не дают host isolation, глобальной транзакции источников
или защиты от hostile writer. Если запись завершилась неизвестно, сначала
проверить сохранённый файл; не повторять вслепую. Совпадение ID в другом файле
не обнаруживается глобально. Новую редакцию различает и сохраняет caller.

CLI возвращает hash фактического HTML, входа и содержания без attention.mode.
Последний позволяет проверить одинаковую factual projection при другой глубине;
он не удостоверяет человека, authority, истину или отсутствие omissions.
Старые snapshots/ответы не меняются при обновлении helper/style. Смена фактов
требует новой revision, а asOf не подтверждает текущую пригодность.

Общий stylesheet — `tools/decision_view/style.css`; он встраивается, поэтому
готовые файлы не зависят от папки tools. Связанные материалы остаются отдельными:
при передаче перенести необходимый комплект с сохранением относительных путей.
Не открывающаяся ссылка имеет fallback с точным именем/редакцией для запроса автору.

## Проверка достаточности

Перед передачей восстановить из документа предмет, вывод, critical limits и next.
Проверить соответствие всем опорным фактам, включая раскрываемые слои; не спрятал
ли автор условие в `standard/deep`. У Review/Result не должно быть скрытого запроса
приёмки. Проверить переносимость, узкий viewport, читаемые заголовки и таблицы,
клавиатурное раскрытие, смысл без цвета/сети/JS в доступном браузере.
Успех сборки/agent trial не доказывает понимания человеком или экономии времени.
