# Навигация по DPF

[Указатель методов](dpf/METHODS.md) охватывает 17 DPF: 15 базовых и дополнительные DDB/SVV. В нём 273 адресуемых метода: 261 из базовых DPF и 12 из дополнительных. [Репертуар](../frameworks/dpf/REPERTOIRE.yaml) закрепляет редакции; навигация не заменяет чтение тела выбранного метода. Наличие DPF не требует его применения.

Число методов поставки — число уникальных полных ID в таблицах указателя методов. Каждый ID должен вести к телу метода в выбранной редакции DPF. Составные ID, например `ME.6.MC` и `OPS.8.1`, учитываются отдельно. Повторные ссылки и упоминания одного ID не увеличивают число методов.
