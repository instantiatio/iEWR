# Каталог инженерных references

Каталог хранит необязательные selection/content aids, а не runtime modules.
Текущие владельцы: [F](../modules/formation/DOMAIN_WORK.md) — Method/formation
и intended basis; [I](../modules/interaction/HUMAN_INTERACTION.md) — представления.
S связывает источники; G сохраняет direct authority grounds; L — assessment use.
Каталог не имеет writer, status service, scheduler или собственного authority.

| Reference family | Когда полезен | Consumer |
|---|---|---|
| [DPF: единый указатель методов](dpf/METHODS.md) | Найти и применить нужный предметный вклад с сохранением source conditions | S/F; производные aids, не runtime routes |
| [Инженерные представления](engineering_views/README.md) | Показать material отношения предмета для конкретного решения | I; domain content остаётся у direct owner |
| [Организация работы и Method cues](working_process_compositions/README.md) | Разрешить нужный вопрос Method, координации или concern/result coverage | F; это не библиотека runtime routes |

Начать с current question, exact subject и receiving use. Reuse достаточный
результат; при необходимости выбрать подходящие cues и проверить их direct
source/applicability. Нет подходящего cue — допустимы Direct Work или нужная
formation по текущим основаниям. Наличие DPF, ссылки на метод или его номера
не требует Work Context, Working Process, Task/Run, Verification или Admission.
Решение нужно лишь для use/commitment, которому оно действительно требуется.

IDs EV/CC/EM/WM и прежние WA aliases сохраняют навигационное значение.
Исторические решения читаются в исходном named use; каталог не мигрирует records.
FPF/DPF/LPF остаются independent sources. HAWS, AI SDLC и FC-13 не Core routes.
