# Навигация по DPF

[Указатель методов](dpf/METHODS.md) охватывает 20 DPF: 18 базовых и дополнительные DDB/SVV. В нём 303 адресуемых метода: 291 из базовых DPF и 12 из дополнительных. [Репертуар](../frameworks/dpf/REPERTOIRE.yaml) закрепляет редакции; навигация не заменяет чтение тела выбранного метода. Наличие DPF не требует его применения.

Число методов поставки — число уникальных полных ID в таблицах указателя методов. Каждый ID должен вести к телу метода в выбранной редакции DPF. Составные ID, например `ME.6.MC` и `OPS.8.1`, учитываются отдельно. Повторные ссылки и упоминания одного ID не увеличивают число методов.

ISEC 0.12 и SPSEC 0.2 включены в базу для выбора по задачам общей ИБ и безопасной разработки ПО. Их `seedOnly`, самостоятельные редакции и ограничения личного использования сохраняются; регистрация не является новой оценкой качества.

CDP 0.1.2 включён в базу для коммуникационного дизайна статей, отчётов, книг, презентаций и веб-публикаций. Десять методов выбираются по вопросу; Guide и пределы авторских проверок сохраняются. Для обычного применения не требуется предварительно читать WEP, VID, EXD, CHK или FPF.
