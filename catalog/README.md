# Навигация по DPF

[Единый указатель методов](dpf/METHODS.md) помогает найти нужный вклад в базовых 15 DPF. [Репертуар](../frameworks/dpf/REPERTOIRE.yaml) закрепляет их редакции; навигация не заменяет чтение original body.

Состав проекта может расширяться по согласованному scope. Устройство работы, роли и представления формируются под задачу; каталоги Working Process и Engineering Views прежних выпусков не являются обязательной частью этой конфигурации.
