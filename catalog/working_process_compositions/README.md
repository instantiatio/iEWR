# Организация работы и Method cues — reference для F

Старое pathname сохранено для consumers. [F](../../modules/formation/DOMAIN_WORK.md)
владеет вопросом Method и intended basis. Каталог предлагает bounded cues:
CC — контекстные композиции, EM — Method families, WM — concern/result fragments.
Они не runtime modules, workflow definitions или готовые approved processes.

Начать с question/use/exact subject, direct constraints, текущего результата и
недостающего decision-changing basis. Выбрать только useful cue, проверить его
direct source/applicability и counter-signals. Нет fit — нормальная formation
или Direct Work. Ни admitted context, ни selected DPF, ни Working Process не
являются обязательным prerequisite. WorkPlan нужен только для intended coordination.

Порядок задают реальные dependencies выбранного Method и receiving uses.
Карточка не назначает performer/authority, не создаёт X action, E effect или
L Verification. C не исполняет карточки как workflow. Полезная комбинация cues
не должна сливать разные owners, state, evidence и authority. Project/domain
concerns сохраняются, даже если ни одна карточка их не описывает.

Показать рекомендацию и trade-offs понятным языком, существенные omissions/gaps,
эффекты и нужный выбор, если он действительно требуется. I управляет подачей,
G проверяет direct answer; обязательных заголовков и process approval нет.
Существующее решение/record сохраняет exact historical scope; новое use отдельно.

[CATALOG](CATALOG.md) сохраняет CC-01…06, EM-01…05, WM-01…08 и WA aliases.
Domain/engineering views — [EV reference](../engineering_views/README.md),
Method-specific representation может быть другим. Не выводить source truth,
formal Work membership или полноту результата из названия/диаграммы/карточки.

Source/edition/currentness pin остаётся у S/F. Historical external bibliographic
references не проверялись заново в B7; это provenance, не current endorsement
или positive SoTA. Consequential source claim требует exact adequate basis.
Changed claim: depends / mentions only / unresolved, bounded affected receivers,
coverage gaps и reopen; citation не dependence. Material conflict direct owner.
External capabilities: capability_only / process_bearing_mappable /
process_incompatible; useful content без foreign lifecycle/authority.

[Optional record](templates/WORKING_PROCESS_COMPOSITION_RECORD.yaml) нужен для
recoverability выбранной F basis, не для соблюдения структуры. Schema 2 не
переписывает schema 1 historical decisions. Runtime не читает YAML как очередь.
