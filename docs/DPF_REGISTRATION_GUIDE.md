# Проектные DPF и источники методов

[AGENTS](../AGENTS.md) различает базу, проектный репертуар, сохранённые источники отдельного применения и доверенные ссылки. Получение и включение выполняются по инициативе Human либо согласованному предложению; доступная библиотека сама разрешения не создаёт.

Для устойчивого обнаружения используйте существующий `project/dpf/REPERTOIRE.yaml` или достаточный проектный указатель. При отсутствии нужды в устойчивом репертуаре сохранённый источник можно применять напрямую в согласованном scope. Не создавайте карточку на каждое чтение. Неизвестные entries рассматриваются по содержанию наравне с известными.

У сохранённого источника нужны различимые identity/edition, actual locus, происхождение, существенные пределы и доступность. При употреблении существующего JSON-in-YAML формата базового repertoire сохраните его имена полей; сам этот формат не обязателен для нового проекта. Для пользовательского источника обычное место — `external-sources/external-dpf/`. Не копируйте достаточный уже сохранённый экземпляр только ради регистрации и не исполняйте содержимое источника.

Новая редакция не переключает прошлые uses. Прямое удаление записи из репертуара не удаляет источник, историю и прежние основания. Изменение значений требует проверки зависимых выводов. Оригинальный FPF подключается отдельно по [его руководству](FPF_CONNECTION_GUIDE.md), а не маскируется под project DPF.
