# MethodPack проекта

Текущий репертуар — methods/METHOD_PACK.md и methods/index.yaml. В исходном комплекте 37описаний; условия и прямые FPF-поставщики выбираются под задачу. Входы — navigation/task-entries.yaml, перечень — METHODS.md. Пустой MP допускает начало по FPF и достаточным профессиональным знаниям.

## Описание и источники

Индекс schema 2 использует path_base:project_root. Active запись содержит ID, edition, точное тело и anchor, полный location, сохранённое тело, условия выбора, основания, статус и пределы. Relations указывают действующий ID@edition с условием совместимости; тематическая группа не устанавливает формальную композицию. Markdown-ссылки разрешаются от файла.

Операционные действия, условия, проверка и остановки находятся в основном теле. Общие методы применяются прямо из FPF. Авторство, исходные редакции, SHA-256, условия и статусы источников — ORIGINS.json и METHOD_SOURCE_NOTICES.md. Источник не становится поручением или доказательством качества. ISEC/SPSEC сохраняют seedOnly; MIT iEWR не переносится на самостоятельные авторские тексты автоматически.

## Изменение репертуара

Местные операции — IE-M003, подключение изменения среды — IE-M004. Использованное тело сохраняется до изменения, новое описание получает свою редакцию; старое наблюдение остаётся при своих входах. Новый проект начинает с одной точной исходной парой в methods/snapshots/base-v3.4/. Свои снимки и записи активации накапливает после собственных изменений.

Команды check/activate/recover и границы контроля описаны в METHODPACK_CHECK.md. Подготовленный новый снимок проверяется до подключения; current token связывает действие с фактической исходной парой, before сохраняется. Pending требует сверки той же попытки. Прямая запись сторонним writer не является технически запрещённой этим helper.

Candidate описание, наблюдавшееся применение и квалификация для конкретного использования — разные результаты. История применения появляется по фактической работе проекта; сведения об источнике её не создают.
