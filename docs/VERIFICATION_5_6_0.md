# Проверки iEWR 5.6.0 Beta

## Предмет и среда

Проверен локальный кандидат 5.6.0 Beta на основе exact ZIP iEWR 5.5.8 Beta, 134 файла,
SHA-256 6728269ac1340f275e809afcefc2e00b57ae87cc4d45d0000c250ae00d9cd8e4.
Проверенная среда — macOS 27.0.1 arm64, Python 3.14.6. Ни версия продукта,
ни успешный check не являются приёмкой, полномочием или разрешением публикации.

## Программные проверки

20 автоматических тестов прошли: 13 сценариев FPF helper и 7 сценариев упаковки.
Они проверяют реальные границы чтения/записи и отказов; связанные assertions
в одном сценарии не считаются независимыми доказательствами общего качества.

FPF helper: неактивная копия и отсутствие сети по умолчанию; намеренное ручное
подключение; точное чтение Unicode с продолжением и ограниченным диапазоном;
навигация без заголовков внутри code fence; drift; смена редакции; обязательный
digest продолжения; отключение с историей; смена Core; небезопасные paths и
symlink; занятый lock; закреплённая загрузка с проверкой Git blobs; повторная
загрузка и отказ без публикации повреждённой редакции. USING-FPF.md не загружается,
а успешный fetch не подключает источник.

В первой попытке 12 сценариев остановились на системном /var symlink временной
папки macOS. Fixture переведён на канонический путь /private; продуктовый запрет
symlink сохранён. Повторные 13 сценариев прошли. Для полного flow скачивания
сетевой transport подменён фиксированными ответами. Это не настоящая загрузка
FPF-Spec. Живой GitHub API при проверке вернул 403 rate limit; реальная загрузка
закреплённого LICENSE по HTTPS с проверкой Git blob прошла. Полная сетевая
загрузка оригинального FPF остаётся не испытанной на живом сервисе.

Упаковка: локальный пользовательский FPF и connection исключены; private файлы
нельзя добавить в manifest; отсутствие KCAE выявляется отдельно; повреждение
source, прежний edition с новым digest, лишний или отсутствующий файл
отклоняются; ZIP читается обратно точно, существующий архив не перезаписывается.

## Целостность и совместимость

Выбранный состав — 138 файлов, 14 DPF, 228 уникальных адресуемых методов.
Все 216 прежних ID сохранены; добавлены SYSE.53 и 11 KCAE. Каталожные ссылки
сверены с заголовками original body и их якорями. Собственные локальные ссылки
проверены, сломанных нет. Внешние ссылки внутри неизменённых авторских текстов
не объявляются проверенными локальными файлами.

Тринадцать авторских оригиналов закреплены по commit
9e1c48349bd0a06d8d49e2de45fbcff386d47ae5 и сверены с Git blobs. Проверены все
14 bindings repertoire, manifest/configuration digests, Python AST и import DAG.
Core, SDLC 0.1.0 и 31 прежний Python-файл modules/adapters/app совпадают с baseline.
Изменения Python ограничены новым optional FPF helper и упаковкой.

В payload нет оригинального FPF, подключения, истории пользователя или материалов
разработки. Сам manifest не хеширует себя. Проверка конкретного собранного ZIP
и его SHA-256 фиксируется во внешней квитанции при передаче; она не встраивается
в собственные bytes архива. Это позволяет проверить именно переданный экземпляр.

## Пробы агента и чтение документации

Baseline и первая редакция кандидата проверялись чистыми агентами без переписки
разработки на одинаковом небольшом приложении. В brief были создание, чтение и
удаление заметок; реализованы только создание/чтение, два теста проходили. Обе
версии выявили отсутствие удаления и не объявили весь результат готовым.
Повторного разрешения на уже порученную проверку не запрашивали, код не меняли.

Одинаковый следующий запрос совместно обсудить повторное удаление привёл к
сравнению KeyError и успешного повтора с сохранением решения человека. В первой
редакции кандидата обнаружен дефект: смысл перехода объяснён, буквальная метка
S3/S4 не выведена. Результат сохранён как неуспех критерия подачи. После уточнения
I/AGENTS свежая проба candidate-v2 вновь выявила неполную реализацию, затем
показала S3 · при переходе к совместному мышлению без дублирования в final.
Ответ «Оставляем KeyError» зафиксировал выбор и не отменил запрет реализации.
Следующее поручение самостоятельно составить критерии вызвало S4 · Самостоятельный
анализ; критерии подготовлены без реализации или написания тестов. Обе метки
появились только на соответствующих переходах в commentary.

Это испытания конкретных промежуточных selected конфигураций; их hashes и
протоколы сохранены в материалах разработки. Перед передачей отдельно сверяются
изменённые после пробы файлы и идентичность проверенных правил конечному составу.
Финальная редакция текста отчёта сама не объявляется повторным агентным trial.

Независимый читатель README, release notes и FPF guide восстановил назначение,
первое действие, изменения и ограничения. Найденное старое число 12 авторских
DPF в одном абзаце README исправлено на 13. README и release notes полностью
прочитаны автором, изменённые места перечитаны. Это чтение агентом, не проверка
понятности с реальными пользователями.

## Пределы вывода

На выбранных задачах baseline тоже работал правильно: уменьшение лишних
остановок и общая надёжность классификации S3/S4 не доказаны. Для технических
препятствий, параллельных ветвей, re-entry с неизвестными effects и иных
ситуаций выполнено сопоставление правил, но отдельные агентные пробы не заявляются.
Ограниченное успешное наблюдение не заменяет human usability study, FPF semantic
conformance или квалификацию всех host/ОС/Python. Python 3.10+ — интерфейсный
минимум, не испытанная матрица версий.

Helper предназначен для одного согласованного локального writer; checks/lock
не являются hostile-writer sandbox. Сохраняются прежние ограничения POSIX,
Decision View и distribution_ready=false для локального экспериментального SDLC.
Исходный FPF не скачан и не активирован для этой доработки. Приёмка и публичное
распространение нового кандидата не следуют из завершения этих проверок.

из успешных тестов. Публикуется неизменённый архив: 138 файлов, SHA-256
`3b6f4aec471f9fa56b0cf713a69746e6fa3a10a4561a28734fadf681d35a87a4`. Его внутренние статусы относятся к моменту
фиксации кандидата. [Страница выпуска](https://github.com/instantiatio/iEWR/releases/tag/5.6.0-beta) отражает факт публикации.

В репозитории уточнены только сведения о выпуске и соответствующие digests;
содержательные инструкции, original DPF и код совпадают с проверенным ZIP.
Статусная строка AGENTS обновлена отдельно и не меняет правила взаимодействия.
