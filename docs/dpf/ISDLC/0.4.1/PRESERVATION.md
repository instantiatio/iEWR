# Сохранность и принятие вкладов

Сопоставлены весь [предшественник 0.3.1-candidate](History/ISDLC.md) и ISDLC 0.4.1, включая Readme, Reference,18 тел, карту, связи, C1–C6 и заключительные условия. Точные hashes и сравнение 216 канонических содержательных единиц — в [PRESERVATION.json](PRESERVATION.json). Это проверка переноса по E.4.PFIP, отдельно от оценки качества E.21.

183 из 216 единиц совпадают после нормализации только адресов Markdown-ссылок и удалённых HTML-адресов. В остальных, кроме двух названных смыслосохраняющих переписей, прежние непустые строки сохраняются в прежнем порядке; добавления проверены отдельно. Этот технический результат сам по себе не доказывает семантическую сохранность. Авторская сверка изменённых отношений и независимые оценки подтверждают её в заявленном scope.

## Публикационная оболочка

Readme сохраняет CODE/RETRY/TRANSITION, их пять полей и обычные действия/возвраты. Убраны невыбранные лимиты Card и пустой защитный аппарат. Preface переименован в единый канонический Reference; три прежние объясняющие части сохранены, четвёртая раскрывает предметную глубину. Lineage-only заголовки перед кодовыми паттернами вынесены из practitioner body; происхождение по-прежнему доступно в Reference и материалах. RawHTML anchors заменены native headings, соответствие старых адресов сохранено в [ADDRESSES](ADDRESSES.md); fixedGit предшественника продолжает обслуживать старую цитату.

Карта покрытия и связи расширены условными предметными входами. C1–C5 сохранены после нормализации адресов/удаления HTML-якоря; добавлен C6, без объявления его выполненным продуктовым испытанием. Издание, источник, лицензии, пределы и пересмотр остаются доступными. Новые внешние DDB/SVV приняты как guidance по конкретному вкладу; перенос всех 12 тел или обязательная Suite не выбраны.

0.4.0 сохраняется как точный объект первоначальной независимой оценки, 0.4.1 — её публикационное исправление. В Git поступает только текущий файл; первоначальные hashes, находки и граница повторной проверки остаются в материалах рецензентов. Прежняя опубликованная методика сохраняется в Git-истории.
