# ISDLC 0.5.0 — зависимая перепроверка

Итог: **admissibleForDeclaredDPFUse** для обычного применения подготовленным читателем. Полная текущая матрица — 18 методов × 19 E.21 координат, 12 DA и 13 PFM; ordinary floor 4 достигнут, средний балл не вычислялся.

Неизменность полного текста, всех 18 тел, initial и файлов round-1 подтверждена. Их содержательные оценки, зрелое сравнение, SoTA и первоначальный F.19 переиспользованы с явной проверкой совпадения предмета, редакции, читателя, условий и назначения. Это знакомая зависимая перепроверка; нового холодного испытания не было.

**ISDLC-SRC-1 закрыта.** Historical locators старого/нового SOURCES и shared теперь указывают на точные исходные Git objects; четыре фактически прочитанных локальных объекта дали ожидаемые source hashes. Исходный VID отделён от использованного пакетного носителя. D9 повышена с3 до4; PFM3/PFM8 проходят.

**I04 закрыта.** Старая карта на тексте с четырёхстрочным preface действительно не восстанавливала заявленный оригинал. Новая карта учитывает preface, совпадает с текущим SHA и точно восстанавливает тот же исходник. Scope явно полный, `authoring_change=true`, не link-only. Нового обязательного дефекта в Status не установлено: перед ToC прямо определён смысл edition, header отдельно сообщает guidance/условия; H10 не требует буквального равенства этих полей.

Текущие локальные права, исторические разрешения и отсутствие публикации согласованы в сопровождении и регистрации. Достаточность текста не устанавливает правильность реализации, промышленную пригодность или человеческое понимание. Проверена доступность сохранённых Git objects; доступность веб-страниц не выводилась.
