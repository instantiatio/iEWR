# Данные и проверки программного обеспечения

Два самостоятельных DPF, изготовлены 19.10.2026: [DDB 0.1.1](../../DDB/0.1.1/History/DDB.md) и [SVV 0.1.1](../../SVV/0.1.1/History/SVV.md). В каждом шесть методов, руководство входа и архитектурная справка.

[Принятые границы](BOUNDARIES.md) разделяют построение/изменение данных и получение оснований проверочного вывода. Решение принято Albert до authoring. Точное поручение: «Принимаю предложенные границы. Начинай разработку DPF данных и БД и DPF верификации и валидации по каноническому методу FPF, со связями с ISDLC и проверками. Без лишнего усложнения». Исторические формулировки в BOUNDARIES и ARCHITECTURE_BASIS относятся к моменту предложения; результат разработки и текущая оценка находятся в материалах DDB/SVV.

| DDB | SVV |
|---|---|
| .1 Смысл сохраняемых фактов | .1 Свойство и oracle |
| .2 Зависимости и ограничения схемы | .2 Различающие случаи |
| .3 Инвариант, конкуренция и повтор | .3 Средства и граница наблюдения |
| .4 Запросы и физическое представление | .4 Состояния и частичные отказы |
| .5 История и производное | .5 Пригодность для нужной задачи |
| .6 Эволюция и восстановление | .6 Вывод и повторная проверка |

DDB передаёт модель, инварианты и протокол изменения; SVV при необходимости возвращает наблюдения, дефекты и границы вывода. Обычная достаточная работа ISDLC сохраняется. Это выборочная предметная глубина, а не обязательный проход по двенадцати пунктам или объявление Suite.

Начать с [материалов DDB](../../DDB/0.1.1/README.md) или [SVV](../../SVV/0.1.1/README.md). Общая основа — [исследование](Research/REPORT.md), [карта покрытия](Research/COVERAGE_MAP.json), [источники и их границы](SOURCES.md), [пробы](Trials/README.md). Два отдельных агента выполнили полные оценки E.21 и DPF; замечания устранены в 0.1.1. Пять lenses со scope добавлены в Bias-Annotation; DDB.2 получил пригодный AB/AC и явный компромисс с единым отношением.

[Перенос](TRANSFER.md) сохраняет смысл проверенных текстов и точные связи с оценками. Он публикует результаты в существующую приватную библиотеку; исходный проект и базовая поставка iEWR не переключаются.
