# Соединения VID0.3.1: адресная авторская проверка

Входы взяты из явно потребляемых результатов таблицы VID.Reference:4 и из реальных решений в VID.1/.5/.6/.10. Задача — установить, что текущие поставщики дают нужный смысл и что старый ISDLC больше не нужен в выбранном составе. Подготовка и визуальные методы VID сохраняются.

| Получаемый результат | Проверенные поставщики | Вывод и предел |
| --- | --- | --- |
| Пользовательский путь, состояния, ввод, доступность, дизайн-система | ISDLC.1/.2/.6@0.4.1; прежде .6@0.3.0 | Полный Solution.6 совпадает побайтно. Текущий метод даёт те же входы для визуального выбора; это не проверка конкретной реализации интерфейса. |
| Значение результата/ошибки/конфликта/неизвестного исхода | ISDLC.5/.7@0.4.1 → VID.10 | Новые .5/.7 различают эффект и пригодное подтверждение, сохраняют идентификатор/параметры и продолжение после reload. VID.10 получает значение состояния от поставщика и выражает его, сохраняя ввод и доступное действие. Возврат нового серверного конфликта поставщику сохранён. |
| Совместимый состав и изменение/проверка полного пути | ISDLC.9/.10/.16/.11@0.4.1 → VID.5/.6 | Solutions.9/.10/.16 совпадают с прежними. .11 добавляет различающие отказы и условное углубление SVV, сохраняя достаточную простую проверку. Визуальная проба не заменяет полный пользовательский сценарий. |
| Содержание, голос, неизменяемые строки и итоговая сверка | WEP.2/.7/.9/.12@0.1.6 | Текущие тела дают нужные операции и возвращают факты их владельцу. Сопоставлен контракт VID и текущий поставщик. Полный WEP0.1.4 не найден в видимой локальной истории; тождество его методов нынешним не предполагается. |
| Перенос визуального решения в презентацию | Внешний BPD1.1 | Условие сохранено, BPD не включён и не требуется для web-задачи. Перед зависимым применением нужны доступный согласованный источник и подходящий результат. |

Ограниченная браузерная проба Chrome155: 320/1280px, эффект записан в синтетическом локальном хранилище, тело подтверждения повреждено. После reload ввод и unknown сохраняются; сверка возвращает результат с одним эффектом. Контрпример, объявляющий успех по transport200, выявлен тем же критерием. Факты — в UI_RESULTS.json. Это авторская проба DOM/состояний на искусственном стенде, без реального сетевого/серверного отказа, machine crash, человеческого восприятия, эстетической приёмки или общего WCAG-вывода.

По F.19 выполнено экспертное чтение изменённого связного раздела: участники, получаемые результаты, условность BPD, stop/return и границы вывода сохранены. Это авторское чтение. Последующая отдельная полная оценка и зависимая перепроверка сохранены в [VERIFICATION](VERIFICATION.md); первое восстановление и ограничения F.19 приведены отдельно.
