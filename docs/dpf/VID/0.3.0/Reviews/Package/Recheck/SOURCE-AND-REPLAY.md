## Что изменилось в доступном объяснении

Current .9:4 теперь даёт положительную условную операцию: значимый набор → достаточный готовый набор → реальный фон/текст/размер → функция/вес/выравнивание → допустимое смысловое исключение → граница правки asset и проверки аудитории. Current .9:5 содержит изменяющий решение worked case; .9:7 проверяет нужный результат; .9:11 раскрывает принятие/адаптацию/альтернативу/ограничение/refresh. Это дополнение содержания в той же форме, а не измеренный выигрыш оформления.

Две ложные подстановки теперь отвергаются самим публичным объяснением: equal viewBox не доказывает одинакового воспринимаемого веса; filled-selected не обязательно нарушение единства. Достаточные labels/штатные controls остаются разрешённым завершением. Человек сохраняет окончательную эстетическую оценку; собственная компетентность AI не становится правом менять защищённый asset.
