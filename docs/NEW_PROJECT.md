# Начало проекта и перенос

Этот каталог уже подготовлен для нового проекта. Начните с README.md, AGENTS.md и текущего прямого поручения. В methods/ находится стартовый репертуар, в external-sources/fpf/ — точный оригинал FPF, в navigation/ — средства поиска. project/source/, project/reference/, project/artifacts/ и project/handoff/ пусты. CURRENT.json появляется, когда действительно нужны материалы продолжения.

Чтобы начать ещё один проект, распакуйте исходный чистый архив в другой пустой каталог. Используйте весь комплект с его README, PACKAGE, источниками, инструментами и INSTALLATION. Если рабочий экземпляр уже накопил собственные методы и материалы, используйте для нового старта сохранённый исходный ZIP: копирование рабочей папки может перенести чужую историю.

Для перехода существующего проекта сначала сохраните его исходники, данные, методы, решения и незавершённые вопросы. Поручите агенту подготовить перенос с учётом этих материалов и проверить результат. Не накладывайте ZIP поверх рабочего проекта вслепую. Местная подготовка и подключение среды описаны в SELF_DEVELOPMENT.md; предметные данные и доступы устанавливаются отдельно.

При доступном Python начальная проверка репертуара: python3 -B tools/methodpack.py check --json. Проверка структурного индекса FPF: python3 -B tools/build_fpf_index.py --check. Для новой пары MethodPack выберите реализацию IE-M003 по METHODPACK_CHECK.md: готовый helper с командой activate либо ограниченный файловый путь ADE. Приведённые команды проверки требуют Python; его отсутствие само не запрещает достаточную проверку/обновление MP другим поддержанным способом. INSTALLATION перечисляет байты исходного комплекта; после развития проекта прежняя инвентаризация сохраняет свою исходную область, а изменённый состав учитывается отдельно.

Версия продукта 7.0.0 и редакции библиотеки методов самостоятельны. Готовый репертуар не устанавливает новые задачи и не требует проходить все 37 методов или семь функций. Достаточную основу агент выбирает для текущего использования.

Обязательного Python для начала и текущей работы нет. Поставленная пара FPF уже готова к чтению. По поручению сменить её редакцию получают согласованный комплект оригинала и индекса с происхождением и проверкой по FPF_INDEX.md; локальная перегенерация не является обязательным шагом нового проекта.
