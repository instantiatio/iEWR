# iEWR 5.6.3 Beta — основа и пределы

Дата: 2026-10-07. Коррекция правила изготовления DPF, проверки, публикация GitHub Release как Latest и обновление главной страницы прямо поручены Human. Поручение разрешает этот выпуск; повторная приёмка как дополнительное условие не вводится.

Основа — опубликованная [iEWR 5.6.2 Beta](https://github.com/instantiatio/iEWR/releases/tag/5.6.2-beta), commit `7ed84ee` (полный commit фиксируется в материалах разработки), exact ZIP SHA-256 `d83c73910d13d30d7706dd75f926bbd1da820912b363d83642385c104b774ff1`, 141 файл. ZIP сохранён; до правок его payload полностью совпал с checkout 5.6.2. Прежний выпуск не изменяется.

Изменены dispatcher, F/S и два руководства: для нового/содержательно перерабатываемого DPF требуется выбранная точная редакция оригинального FPF и достаточное чтение применимых положений до architecture/authoring. Если подключения нет, предложение подключения обязательно. Обычные задачи, готовые DPF и редакторские правки исключены; скрытый fetch/connect/full read не разрешён. Независимое исследование предмета может продолжаться с честным предварительным статусом.

Core, S3/S4, runtime-файлы и 14 активных DPF/242 метода сохраняются. Instantiatio SDLC остаётся авторским кандидатом 0.2.2 с прежней упаковочной привязкой 0.2.2-package-5.6.2. Новая версия iEWR не переименовывает и не повышает его статус.

`distribution_ready=true` сохраняет прежние основания распространения и не обозначает промышленную квалификацию. `publication_authorized=true` отражает прямое поручение; `public_release=false` внутри exact ZIP относится к моменту фиксации до публикации. Факт публикации проверяется по [GitHub Release 5.6.3](https://github.com/instantiatio/iEWR/releases/tag/5.6.3-beta); после проверок ZIP не пересобирается.

Проверки и их границы — в [VERIFICATION.md](VERIFICATION.md). Это instruction-led изменение, не технический enforcement host, новая семантика Core, formal Work/Method admission или гарантированная квалификация агента. Свидетельства сохраняются вне product payload. Подключение FPF не расширяет полномочия; прежние ограничения host и источников остаются.
