# iEWR 5.5.6 Beta — сведения о зафиксированном выпуске

29 сентября 2026. Версия `5.5.6-beta`, имя `iEWR 5.5.6 Beta`.
`status=release_authorized`, `publication_authorized=true`, `public_release=false`,
`distribution_ready=false` на момент фиксации ZIP. Пользователь прямо поручил
собрать эту версию и опубликовать её как Latest на GitHub. Факт загрузки и
публикации устанавливается отдельно по [странице выпуска](https://github.com/instantiatio/iEWR/releases/tag/5.5.6-beta).
Подготовительный статус неизменяемого архива не отменяет последующую публикацию.
Он также не означает общей квалификации агента, источников или технических controls.

## Основа и изменения

Опубликованный exact `iEWR-5.5.5-Beta.zip`: 132 файла, SHA-256
`9ab80c335351ff649616c41d2c9e22694162798a45b7b739cbe7d2918ca0caae`.
Соответствие этого ZIP опубликованному asset подтверждено GitHub. Архив сохраняется
без изменений. Рабочие редакции `intent-chat-answer-r01` и `intent-realization-r01`
сохранены отдельно с проверками; финальные I/F/X совпадают со второй редакцией.
Назначение версии меняет документацию и inventories, не эти инструкции или код.

Добавлена активная помощь в формировании задачи: контекст, разные постановки,
примеры, ограниченные пробы и локальная коррекция. Отделены ясная постановка,
достаточные условия ближайшего действия и фактический результат. Обязательных
интервью, стадий, новых owners или согласований не введено. Новые Decision View
копируют читаемый ответ для исходного чата; reader поддерживает `--chat`, прежний
HTML и единый учёт повторов/конфликтов. Числовые записи 2 и 2.0 эквивалентны при
сохранении точной записи. Core, owner code, DPF и полномочия сохранены.

## Проверки и пределы

На рабочей редакции выполнены 16 проверок в Chrome 154.0.8037.58: реальное
копирование и вставка на локальной странице, ручной fallback, свободный ответ,
параметры, черновик, редактирование и отсутствие автосогласия. Отказ API и async
races воспроизведены подстановками. 17 Python проверок охватили новый текст,
точность комментария/единиц, чужую редакцию, legacy HTML, повторы и конфликты.
Эти программные файлы включены без изменений; результаты переиспользуются по bytes,
не объявляются новыми запусками. Встроенные браузеры и реальный мобильный host
отдельно не квалифицированы; сообщение в настоящий чат автоматически не отправлялось.

Сравнение исходных и изменённых инструкций ограничено выбранными ситуациями:
исходная редакция тоже показывала полезную помощь. Отдельный агент на чистом
`intent-realization-r01` без истории разработки выполнил четыре последовательных
хода: обычную правку, подготовку при недоступной CRM, пример дашборда только в
разговоре и его изменение после коррекции. История между ходами сохранялась;
это не четыре независимых испытания. I/F/X перенесены в 5.5.6 побайтно.
Общее улучшение поведения и снижение нагрузки на человека не доказаны.

Версия и новые inventories проверяются отдельно: выбранные 132 файла, digests,
import DAG, чистая распаковка, CRC/readback и соответствие тега ZIP. Точные
результаты публикуются во вложении VERIFICATION.md. Публикация и Latest не
означают приёмки результата для любой инженерной задачи или квалификации live host.
Унаследованные ограничения POSIX-адаптера и внешних ссылок DPF сохраняются;
path-only проверка обнаруживает 46 унаследованных неразрешимых локальных ссылок.
Bundled DPF baseline — `iEWR-dpf-5.5.3`. Полный FPF не требуется и не загружался.
Python 3.10+ — минимальная версия интерфейса, не проверенная version matrix.
