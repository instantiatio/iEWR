# iEWR 5.5.8 Beta — основа и пределы выпуска

2 октября 2026. Версия `5.5.8-beta`, имя `iEWR 5.5.8 Beta`.
Публикация как Latest и обновление главной страницы разрешены текущим прямым
поручением Human. Статус в точном ZIP — `release_authorized`,
`publication_authorized=true`, `public_release=false` на момент его фиксации.
Факт последующей публикации отражает [страница выпуска](https://github.com/instantiatio/iEWR/releases/tag/5.5.8-beta).
Архив после проверки и публикации не пересобирается.

## Исходная поставка и изменения

Прямо выбранный пользователем `iEWR-5.5.7-Beta.zip`: 132 файла, SHA-256
`15c68a5f9b5e0a320e232ad3da518cd62a2c6c34196a5711e1b248d57fad2f2e`.
До доработки все файлы рабочей поставки совпадали с ZIP. Репозиторий main
`98f8a18b13c7daa3ba3262fb272a4bff7c71d6d7` отличался шестью файлами сведений
после публикации; прежние статусы не подменяют выбранную пользователем основу.
Исходный архив и сведения предыдущей редакции сохраняются.

Обновлены 11 внешних DPF, добавлен CHK; исходные bytes взяты из commit
`d4f6b0ba1a4db119fecf8d5b9d2b526633f2e58a` Engineering DPF Suite.
Авторские даты, локальные revisions, digests и лицензии различаются в реестре.
Сохранён локальный SDLC 0.1.0. Всего 13 DPF, 216 адресуемых методов.
Уточнены F/X/R и инструкция саморазвития: смысл проверки, использование
инструментального вклада, доступность контекста и различающие агентные пробы.
Программный runtime, публичные интерфейсы, архитектурный Core и owner DAG
сохранены. Из кода изменён только maintainer profile состава: добавлен слот CHK.

## Проверки и ограничения

Точные выполненные проверки и их пределы указаны в [VERIFICATION.md](VERIFICATION.md).
Смена источников и инструкции не устанавливают FPF conformance, Method/Work
membership, универсальную компетентность, автономию или качество любой задачи.
Новые методы не создают tool capability, право делегации, обучение модели или
автоматический runtime controller. Проверки относятся к выбранной конфигурации.

`distribution_ready=false` сохраняет ограничение metadata локального SDLC:
проектный экспериментальный текст не становится авторской публикацией Suite и
не получает CC BY от его лицензии. Его bytes не изменены относительно ранее
опубликованной базы; текущее поручение разрешает этот выпуск. Двенадцать
upstream DPF имеют подтверждённые авторские notices CC BY 4.0. Статус
распространения источника, публикация и техническая квалификация различаются.

FPF-Spec не включён и не загружался. Авторские относительные ссылки на внешние
публикации сохраняют upstream base; недостающие источники читаются только по
нужде текущего вопроса. Сохранённые абсолютные исторические ссылки SDLC не
являются переносимыми evidence нового проекта. Python 3.10+ — интерфейсный
минимум, не проверенная матрица версий. Instruction-led правила не являются
техническим guard host; унаследованные ограничения POSIX и Decision View
сохраняются без объявления повторных испытаний неизменённых компонентов.
