# Исходная основа и статус iEWR 5.8.1 Beta

После проверки обновлений dpf-lab Human одобрил WEP 0.1.5 и VID 0.3.0 и поручил: «Ок, обновляем, проверяем, публикуем. Все как обычно». Дополнительно поручено отредактировать README и release notes с помощью WEP. Основание включает подготовку iEWR 5.8.1 Beta, проверки, публикацию проверенного ZIP как Latest и обновление главной; это текущий прямой scope, а не перенос прежнего blanket grant.

Основа — опубликованная [iEWR 5.8.0 Beta](https://github.com/instantiatio/iEWR/releases/tag/5.8.0-beta), ZIP SHA-256 `3d3316d0a4f0daf6f07afd59b492372c2eccf7835e9d7516c8f6527bf3a0dfe3`, main `170a64e6d7788bbd481aa642b1cf9359cef3a8bd`. Архив, exact снимок main, прежние источники и текущие исходные bytes сохранены в истории подготовки вне продукта.

WEP 0.1.5 и VID 0.3.0 взяты из commit `bd1cabb2e0e1757801aab142d44184ee195034ce`. Авторские номера редакций отделены от переносимых `*-package-5.8.1`; изменены только назначения Markdown-ссылок. Остальные пятнадцать источников, включая BPD 1.1, и их bindings не изменены. Текущий состав остаётся 17 DPF и 278 методов. [Происхождение и digests](frameworks/dpf/instantiatio/README.md), [реестр](frameworks/dpf/REPERTOIRE.yaml), [NOTICE](frameworks/dpf/NOTICE.md).

Core, функциональный код и maintainer-профиль слотов сохранены. Новые DPF не создают инструменты, полномочия или обязательную последовательность. Исторические материалы приватного dpf-lab, оригинальный FPF и HUM/WED в состав не добавлены. Прямое применение WEP 0.1.5 к документации этого выпуска не переключает остальные текущие основания молча.

Выпуск [iEWR 5.8.1 Beta](https://github.com/instantiatio/iEWR/releases/tag/5.8.1-beta) опубликован как Latest. ZIP и checksum прочитаны обратно из draft и публичной загрузки; bytes совпали. SHA-256 ZIP — `e9653f6f83216f62f5a2d3588980467112ead62fa416bc45527f746b82c7b795`. Тег `5.8.1-beta` закрепляет commit `fc49b811229886f720b91b5065f19bb558b9c1ae` со всеми 147 файлами проверенного архива. Архив сохраняет состояние подготовки и не пересобирался. Main отдельно отражает публикацию; configuration и manifest согласованы. Remote receipts сохранены вне продукта. Пределы — [VERIFICATION](VERIFICATION.md).
