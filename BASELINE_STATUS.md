# iEWR 5.6.2 Beta — состав и основания

Исправление и публикация прямо поручены Human после уточнения: переименовать основной DPF-файл, исключить старый SDLC, предыдущие версии Instantiatio SDLC и исторические ревью из поставки. Поручение не изменяет содержание методов или Core.

Основа — опубликованная iEWR 5.6.1 Beta, commit `2a117fdce60c3b804bd395a0010e5f9d016f4739`, ZIP SHA-256 `542e1d4272357e6d4bd62be10065212dc39415c9e726e34491c1df9c13c3eec5`. Прежние файлы доступны в [зафиксированной публикации](https://github.com/instantiatio/iEWR/tree/2a117fdce60c3b804bd395a0010e5f9d016f4739) и [архиве 5.6.1](https://github.com/instantiatio/iEWR/releases/tag/5.6.1-beta).

В новом комплекте — 14 активных DPF, 242 метода. Для Instantiatio SDLC поставляются только [основной документ](frameworks/dpf/instantiatio-sdlc/0.2.2/Instantiatio%20SDLC%20DPF.md), [введение](frameworks/dpf/instantiatio-sdlc/0.2.2/README.md), источники и атрибуция. Авторская редакция 0.2.2 сохранена; привязка `0.2.2-package-5.6.2` отражает упаковку и ссылки. Исторических source entries или aliases в каталоге нет; прежние действия восстанавливаются по их прежней поставке, не по молчаливому перенаправлению.

Статус Instantiatio SDLC остаётся авторским кандидатом. Все 18 тел методов и существующие runtime-файлы неизменны. Состав, атрибуция и пределы сверены; `distribution_ready=true` отражает основания распространения, не квалификацию. `publication_authorized=true` — прямое поручение; `public_release=false` внутри неизменного ZIP фиксирует момент до сетевой публикации, факт которой проверяется по GitHub Release.

Проверки и ограничения — в [VERIFICATION.md](VERIFICATION.md). Прежний выпуск не перезаписывается. Новый архив используется и публикуется без пересборки после проверки.
