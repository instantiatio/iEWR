# Основа и статус iEWR 6.0.1

Прямое поручение Human — внести предложенные уточнения S/G/C/R, сохранить компактность, проверить и автоматически опубликовать обновление на GitHub. Основа — опубликованная 6.0.0, commit `219f7dd688a119f124fe185b87542d82ab821c08`, ZIP SHA-256 `6c42aeb33a1948effb5ee3d426cc29adf6dc8ea8c763b74740271725f1de004e`. Перед правкой сохранены точные 49 файлов.

В AGENTS добавлены четыре коротких абзаца: сверка закреплённого источника; предмет и актуальность ответа Human; совместимость вкладов и интеграция целого; передача ожидаемых ответов. Сохранены восемь разделов и весь прежний текст. Core 1.1 RC, его внутренняя редакция 2, пятнадцать DPF, 261 метод, лицензии и структура комплекта не изменены. Новые модули и программные ограничения не вводятся. Оригинальный FPF для этой правки не подключался; переиспользованы готовые методы DPF и предыдущие ограниченные результаты проверки.

Обновлены пользовательское описание и ссылки выпуска по WEP; фактические результаты и пределы проверки — в [VERIFICATION](VERIFICATION.md). Архив — `iEWR-6.0.1.zip`, тег — `6.0.1`. Открытая поставка разрешена текущим поручением; фактические публикация, Latest и main требуют отдельной сверки на GitHub.

## Сохранённая история основы 6.0.0

Human выбрал базу из 15 DPF и вариант 1: принять конкретный кандидат AGENTS с явным уточнением Core и перейти к реализации и испытаниям. Реализация и проверки завершены локально. Последующим прямым поручением Human разрешил публикацию 6.0.0 как Latest и обновление главной ветки; поиск новых FPF/DPF не входит в это поручение. Предпочтение этой сессии — без Human View.

Исходная основа — точная iEWR 5.8.1 Beta, published ZIP SHA-256 `e9653f6f83216f62f5a2d3588980467112ead62fa416bc45527f746b82c7b795` и отдельно сохранённый рабочий состав 147 файлов. История и прямой ответ сохранены вне нового продукта. Старые инструменты могут оставаться в рабочем исследовательском каталоге, но не входят в [manifest](PACKAGE_MANIFEST.md).

AGENTS основан на принятом кандидате; независимое чтение потребовало явно определить существующие метки S3/S4. Core 1.1 RC изменяет EWR-29/INV-15 и метаданные своей редакции. База — 15 DPF, 261 методов; [репертуар](frameworks/dpf/REPERTOIRE.yaml), [навигация](catalog/dpf/METHODS.md), [авторство](frameworks/dpf/NOTICE.md). Основные тексты всех DPF неизменны; DOCA/BPD сохранены в истории, не объявлены активной базой.

[CONFIGURATION.json](CONFIGURATION.json) — статическая опись выбранных bytes для подготовки и проверки комплекта, не runtime, permission registry или схема агентского исполнения. [VERIFICATION](VERIFICATION.md) различает структурные проверки, actual agent trials и непроверенное. Принятие направления не является автоматической приёмкой всех результатов будущих проектов.

## Применение исправлений по FPF

По прямому поручению Human применена подготовленная редакция AGENTS после ограниченного аудита F.19 и связанных положений оригинального FPF. Ссылка на правила README/release notes сохранена. Core 1.1 RC, локальная редакция 2, уточняет EWR-15 по A.15.5; EWR-29/INV-15 остаются ранее согласованным архитектурным выбором. Оригинал закреплён на commit `d9c3dd65da3cd9f7df898698e49c5464dd8a6c4b` и используется для этой проверки вне поставки. Основа выпуска — проверенный локальный комплект с применёнными исправлениями аудита.
