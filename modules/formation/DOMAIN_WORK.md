# F — bounded domain analysis и сохранение результата

Current question, receiving use, exact subject и independent G effect boundary
первичны. Reuse adequate result. При новой содержательной задаче самостоятельно
рассмотреть доступные package/project DPF по [S](../sources/GUIDANCE.md) до
существенного решения о постановке, критериях или способе работы. Это относится
к анализу, требованиям, проектированию, сравнению и поиску причин, где такая
основа ещё выбирается. Пользователь не обязан называть DPF или напоминать о них.

До первой зависимой рекомендации прочитать нужные действия, условия и границы
метода. Это относится и к промежуточным сообщениям: совет о порядке действий,
сроке реакции или критерии уже является решением, даже без итогового заголовка.
До чтения можно назвать входные факты, открытый вопрос и намерение проверить
источник; не предъявлять выбранное действие как уже обоснованное. Если решение
опередило чтение, явно пересмотреть его после проверки, сохранив факт пропуска.

Пригодный метод, дающий нужный текущему результату вклад, применять содержательно:
использовать его различения, действия, критерии и условия, а не только название
или ссылку. Из альтернатив выбрать достаточный набор по вопросу и условиям;
способность рассуждать самостоятельно не является основанием пропустить полезный
доступный метод. Каталог и совпадение слов ещё не доказывают пригодность.

При продолжении на той же достаточной основе переиспользовать прочитанное.
При changed subject/conditions/source или существенном пробеле пересмотреть
только затронутую основу. Механическая правка, форматирование и краткое пояснение
на установленной основе выполняются напрямую без нового обхода DPF. Если после
рассмотрения подходящего вклада нет, выбрать достаточный direct Method или иной
источник. Недоступный каталог, непроверенные источники и отсутствие пригодного
вклада — разные результаты; missing necessary basis удерживает affected claim.

WorkPlan нужен только для координации intended work. Незнакомый namespace не
меняет C/X и не порождает mandatory route. Чтение и применение источника не
требуют отдельного отчёта, регистрации или нового согласования сами по себе.
Выбранный метод читать непосредственно в источнике через
[единый указатель](../../catalog/dpf/METHODS.md) либо авторскую навигацию.
Переиспользовать достаточную прочитанную основу; сохранять только нужные
основания и результаты текущего поручения. Чтение, применение и повторное
использование не создают карточку или отдельный справочный файл.

S сообщает edition/hash/loci/claim limits. DPF и optional LPF применяются
независимо: source availability не applicability, package/project не precedence,
LPF может отсутствовать. Ссылка на FPF не требует полного FPF-Spec. Material
conflict возвращается direct claim owner; newer не значит obtaining binding.

Agent выполняет требуемую domain reasoning/analysis, явно сохраняет premises,
расчёты, alternatives и uncertainty. No automatic source execution. Domain Result
не становится design choice, assignment, закупкой или реализацией. Formal Work
claim отдельно по EXECUTION_BASIS; операционный лог его не заменяет.

Для exact local artifact effect: F OperationBasis задаёт selected Method и
request Binding, target, before/after и receiving use. X independently проверяет
G и unknown history, E пишет intent и вызывает P один раз. ArtifactActuator
реализует только supplied bytes; analysis/correctness не выводятся из receipt.
L оценивает независимый criterion для этого use. Adequate result завершает этот
предмет; достаточность всего поручения оценивается отдельно по его цели и
receiving use. Если остаются необходимые разрешённые части, использовать
пригодный результат и продолжить через existing owners без нового «продолжай».
Сам факт промежуточного Result не разрешает новое поручение или расширение scope.

Для файлов применять [общий порядок](../../project/README.md): по receiving use
различать рабочий экземпляр и сохраняемую редакцию. До решения/проверки/передачи
обеспечить доступ к нужному состоянию и обосновать достаточность сведений.
Проверенную пригодную историю и её обоснование переиспользовать; обычная правка
не создаёт обязательных снимка, отчёта или нового согласования.

Lessons — direct owner result, когда нужен current receiving use. Они не
создают successor, LPF/DPF/Core change. Model/provider advice даётся по exact
observed capability/cost/limits; датированное имя или ranking не superiority.

Для делегации достаточно восстановимой цели, пригодного результата, существенных
критериев/компромиссов, разрешённых effects и условий возврата. Если они уже
даны, не проводить повторное интервью. Агент выбирает обычные способы внутри
этих границ; Human сохраняет решения, которые direct grounds оставляют ему.
Перед gate подготовить соразмерное обоснование по G/I; при нехватке одного
ответа продолжать независимое разрешённое. Формат и число документов выбираются
по use, не по сложности темы.

При проектировании целевой системы исследовать внешний стандарт или guidance
по S только если его attainable ответ может изменить критерий/решение.
SYSE.9 и ME.2/4 помогают ограничить contribution, source и receiving use;
project RMP может помочь при собственном исследовательском вопросе, но не
является обязательным bundled источником. Новое обязательство не возникает
из выбранной библиографии. Достаточный source answer завершает этот вопрос.

Method, MethodDescription, WorkPlan и Work сохраняют разные meanings. Протокол,
исходник, checklist или Loop filename не устанавливает Method identity.
Method Engineering нужен для собственного вопроса identity/fit/composition/
variant/description/worth, а не для каждого выполнения adequate Method.
Когда нужен WorkPlan, связать предмет и горизонт с intended performance, Method,
performer/window и только нужными dependencies/resources/commitments. PlanItem
остаётся declaration-local content; план не устанавливает assignment, readiness
или performance. Readiness A.15.5 нужен только для exact planned entry.
Optional Working Process/Work Context/Entry Decision — производные carriers
только для самостоятельного use; historical meanings — по
[переходу 5.3](../../docs/MIGRATION_5_3.md), без обязательной цепочки документов.
