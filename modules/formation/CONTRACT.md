# F — formation basis для exact replacement

Это выбранное B1 описание bounded Method use, не qualification claim нового
универсального Method. Subject — synthetic project result; receiving use —
получить явно указанный исправленный текст. Inputs: exact target, весь before
и after UTF-8 text, current observation, прямой request и эта description binding.

Способ: если current result уже равен requested after для того же receiving use
и нет unresolved material effect, вернуть reuse. Иначе требуется разрешённая
точная замена всего проверенного before на after; current bytes должны совпасть
с before при попытке и перед commit. Другие targets/изменения не выбираются.
Достаточность replacement задана конкретным task; helper не решает произвольную
литературную/доменную задачу. Не открывать Method Engineering, WorkPlan или Loop,
если этот current use уже имеет adequate basis.

Public EditBasis/FormationResult и form_next_result_basis; поля не дают actual
permission, capability или Work membership. F владеет interpretation question/use
и выбранной basis; current exact refs сохраняет X при attempted action. F не
запускает X/E. Allowed imports: S/L. Не вызывать provider/tool из reasoning
скрытым образом. Formal Work claims отдельно требуют полного прямого basis.

Agent return: reuse → понятный результат и stop; direct → explicit demand X
на конкретный уже разрешённый action; hold → exact missing basis, без successor.
Это несколько обусловленных решений владельцев, не инструкция C исполнять
фиксированные стадии. Лишняя Verification/Admission не создаётся.
