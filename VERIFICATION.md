# Проверки iEWR 5.5.8 Beta

Проверки выполнены 2 октября 2026 на macOS 27.0 arm64, Python 3.14.6.
Основа сравнения — выбранный пользователем ZIP iEWR 5.5.7 Beta, SHA-256
`15c68a5f9b5e0a320e232ad3da518cd62a2c6c34196a5711e1b248d57fad2f2e`.
Эта запись различает проверку состава, наблюдения агентных проб и их пределы.

## Состав и механические проверки

| Проверка | Наблюдаемый результат |
|---|---|
| Архитектурный Core и исполнение | Core Contract и 31 Python-файл modules/adapters/app побайтно совпадают с базой |
| Реестр источников | 13 привязок проверены средствами S; 12 upstream-текстов закреплены по commit `d4f6b0ba1a4db119fecf8d5b9d2b526633f2e58a`, SDLC сохранён |
| Каталог | Все 216 ссылок на методы ведут к существующим файлам и якорям |
| Документация | Новых разрывов локальных ссылок на файлы нет; исходные внешние ссылки DPF не входят в этот вывод |
| Средство упаковки | Корректный состав проходит; изменение текста источника, удаление обязательного CHK, включение проектного файла и перепривязка прежней редакции к другим bytes отклоняются |
| Чистота поставки | Отбор по manifest; исходный ZIP, разработка, данные проектов и агентные пробы исключены |

Выполнены 11 групп технических проверок. При первой подготовке checker обнаружил
созданный проверяющим запуском Python cache; он сохранён вне поставки, последующие
запуски выполнялись с `-B`. В отдельной отрицательной пробе уточнено ожидание кода
отказа `manifest_digest`: исходная проверка отвергла повреждение правильно.
Эти попытки не скрыты и не считаются успешными прогонами.

## Ограниченные агентные пробы

Три агента получили изолированные копии выбранного продукта и пользовательские
задачи без истории разработки. В заданиях не указывались DPF, маршруты или
ожидаемые ответы. Разрешены локальные действия в заданном корне; сеть, внешняя
передача и изменение продукта запрещены. Отдельная техническая изоляция host
для каждого подкаталога не заявляется.

| Задача | Наблюдение |
|---|---|
| Проверить каталог при существующем PASS | Агент самостоятельно выбрал CHK.1/.4/.6 и SIE.10. Выявил `A17 → 1` и `0012 → 12`, отверг пригодность каталога, построил проверку и получил ожидаемые ответы в 11 корректных/дефектных случаях. Исходный checker отсутствовал: проверялась достаточность его объявленных условий |
| Продолжить подготовку заказа после потерянного ответа | Агент использовал точное требование NORTH и запрет отправки, отверг противоречащую summary. Проверил и переиспользовал существующий файл без повторной генерации. Исторический unknown не переименован в success |
| Исправить опечатку и прочитать документацию | Выполнена только требуемая замена в заметке; остальные bytes сохранены. Саморазвитие и обязательное согласование не запускались. Независимое чтение README/RELEASE_NOTES выявило четыре замечания к статусу, числу лицензированных источников, датам и силе обещания сохранности; соответствующие места уточнены |

Хеш конфигурации первоначального снимка проб:
`311df575cb95f4867656dbba6f5b17fac86d961ec63119290494ffd1d7ee30a2`.
Продуктовые файлы во всех трёх копиях после проб сохранили исходные bytes.
После проб уточнялись только README, заметки выпуска, эта запись и производные
configuration/manifest. Испытанные инструкции, каталог, источники и код не менялись;
результаты проб переиспользуются в этих границах. Финальный состав и его digests
определяет [PACKAGE_MANIFEST.md](PACKAGE_MANIFEST.md), а не хеш снимка проб.

## Пределы результата и воспроизведение

Это три наблюдения, а не статистическая оценка надёжности или доказательство
улучшения относительно предыдущего выпуска. Пробы не устанавливают универсальный
выбор методов, удобство человеку, экономию времени, FPF conformance, формальное
Work membership, квалификацию live host или поддержку всех Python/OS.
Неизменённые компоненты не объявляются повторно испытанными во всех сценариях.

`distribution_ready=false` сохраняет прежнее ограничение metadata локального
SDLC; его текст и основание не заменены лицензией Suite. Текущий выпуск разрешён
прямым поручением Human. Публикация и квалификация различаются; подробности в
[BASELINE_STATUS.md](BASELINE_STATUS.md).

Локальную целостность распакованного пакета можно проверить командой:

```sh
python3 -B tools/package/prepare.py check --root .
```

SHA-256 готового ZIP публикуется рядом с архивом на
[странице выпуска](https://github.com/instantiatio/iEWR/releases/tag/5.5.8-beta).
Хеш подтверждает совпадение bytes, но не заменяет изложенные основания и пределы.
