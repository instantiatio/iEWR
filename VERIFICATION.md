# Проверка iEWR 5.6.3 Beta

Дата: 2026-10-07. Предмет — коррекция инструкций изготовления DPF и exact упаковка. Публикация как Latest и обновление главной страницы прямо поручены Human; дополнительная повторная приёмка не вводится.

## Исходная основа

Опубликованная iEWR 5.6.2 Beta, commit `7ed84ee0d097fc0b219de77aef13a74c215eabec`, ZIP SHA-256 `d83c73910d13d30d7706dd75f926bbd1da820912b363d83642385c104b774ff1`. Сохранённый ZIP содержит 141 выбранный файл и до правок полностью совпал по bytes с checkout main. Прежний выпуск сохраняется; условия новой поставки — [BASELINE_STATUS.md](BASELINE_STATUS.md).

Применены ME.12:4, CHK.6:4 и ISDLC.11:4: локальная коррекция, различающие случаи, независимое ожидание и предел вывода. Это применение методов, не claim formal Work/Method admission.

## Пределы и воспроизведение

По одному ответу каждого случая: это не статистическое доказательство причинности, универсального улучшения, сравнение моделей или промышленная квалификация host. Не испытывались фактическая загрузка FPF, authoring с уже подключённым оригиналом и все виды редакторских изменений. Их условия проверены чтением инструкций; это не агентная проба. Запрет сети — условие испытания, а не запрет порученного пользователем скачивания.

Изменение instruction-led, без технического blocker, новых owners, Core semantics, полномочий, автоматического admission или runtime route. Упаковка доказывает состав, а не семантическую правильность всех источников. Прежние испытания исполнителей сохраняют только свой scope; новые live-host испытания не выполнялись.

Из корня распакованного продукта:

```text
python -B tools/package/verify_configuration.py --root .
python -B tools/package/prepare.py check --root .
```

Статус публикации в ZIP фиксируется до remote effect. Tag/commit, Latest, главная страница и digests скачанного опубликованного архива сверяются после публикации и сохраняются отдельно. ZIP после фиксации не пересобирается.
