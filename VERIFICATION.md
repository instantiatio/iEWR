Изменены только 12 файлов: пять инструкций/руководств, README и шесть документов/файлов сведений выпуска. Добавлений и удалений нет. Все 44 файла Python/JavaScript/CJS, 21 файл frameworks, Core и HUMAN_INTERACTION.md сохранены побайтово. Реестр и каталог остаются прежними: 14 DPF, 242 метода. Это статическая проверка целей файлов, не полная проверка внешних ссылок и всех фрагментов источников. README и RELEASE_NOTES прочитаны целиком. Новый ZIP проверяется по CRC, wrapper, 141 файлу и обратному чтению; после публикации его bytes сверяются с загруженным asset отдельно.

## Агентные пробы

Три агента без истории разработки, по одному случаю, унаследованная модель. Каждый получил отдельный чистый экземпляр поставки и обычный запрос; ожидаемая маршрутизация и критерии не сообщались. Явно предложено читать AGENTS.md своего корня. Разрешены локальное чтение и ответ в чате; сеть, запись и делегирование запрещены условиями, не отдельным техническим sandbox. После проб все 141 файла каждого экземпляра неизменны; новых файлов нет.

## Пределы

Это три наблюдения и проверки точных bytes, не статистическое доказательство надёжности, причинности или универсального улучшения. Фактическое подключение FPF, authoring с подключённым оригиналом и редакторские правки отдельно не испытывались; соответствующие инструкции проверены чтением, инструменты не изменены. Live-host квалификация и автоматическая загрузка entry не испытывались. Правило instruction-led, без нового технического blocker, Core semantics, owners или полномочий.

Из корня распакованной поставки:

```text
python -B tools/package/verify_configuration.py --root .
python -B tools/package/prepare.py check --root .
```

Сведения ZIP фиксируются до публикации. Факт GitHub Release, Latest, commit/main, README и digests скачанного архива сверяются после effect и сохраняются отдельно. Предыдущая версия остаётся доступна; ZIP после проверки не пересобирается.
