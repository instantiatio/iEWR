# Попробовать iEWR

Начните с вопроса, приблизительного замысла или инженерного поручения. iEWR поможет уточнить результат, организовать работу и проверить полученное. Осваивать среду можно, задавая агенту вопросы обычными словами.

iEWR 7.0.6 Eternal Alpha работает в вашей агентной среде. Запустите агента в распакованной папке. Предварительно читать Foundations не требуется.

## Требования

- Установленная агентная среда с выполненным входом в аккаунт, доступом к локальным файлам и запуску команд. Для проверки выбран Codex CLI; обычного чата без файлов и исполнения недостаточно.
- Доступ к сервису модели согласно условиям аккаунта и сети. Использование модели зависит от тарифов и ограничений выбранного сервиса.

Распакуйте архив в новую папку. Откройте **iEWR-7.0.6-Eternal Alpha** — папку, содержащую `AGENTS.md`, `START.txt`, `methods/` и `project/`.

## Запустить

Начните новый разговор с агентом, выбрав эту папку рабочей. В уже настроенном Codex CLI соответствующая команда интерактивного запуска:

```sh
codex --cd "/путь/к/iEWR-7.0.6-Eternal Alpha"
```

Подставьте фактический путь к распакованной папке. Сохраните кавычки, если в пути есть пробелы. Для подготовленного опыта ниже разрешите необходимые локальные файловые операции и команды Python. Публикация и доступ к внешним системам для него не требуются.

## Первое сообщение

После запуска агента в папке iEWR можно написать:

- «Что ты умеешь?»
- «Помоги разобраться с моей задачей».
- «Как продолжить этот проект?»

Это примеры, а не специальные команды. Перед началом не нужно знать внутреннюю архитектуру, выбирать методы или проектировать агентный процесс. Опишите то, что уже знаете о желаемом результате: агент может уточнить недостающее, объяснить возможности и предложить полезный следующий шаг. За вами остаются цели, существенные решения и приёмка результата.

### Вернуться к существующему проекту

Откройте ту же проектную папку и начните новый разговор. Попросите агента восстановить текущую цель, результаты, решения, проверки и незавершённую работу, затем обсудите или поручите следующий шаг. При переходе в другую сессию или совместимую агентную среду сохраняйте проектные файлы: они содержат основания для продолжения.

Для готового эксперимента с известными ожидаемыми результатами используйте поручение ниже. Со своей работой можно сразу перейти к разделу [«Перейти к своей задаче»](#own-task). Примеры за пределами разработки ПО — в разделе [«Применение»](/iEWR/ru/applications/).

## Дать поручение

В этом проверенном опыте AI создаёт утилиту проверки сроков коммерческих предложений. Последний день действия и ошибочные даты позволяют проверить содержательное поведение программы.

Для него нужен Python 3; используется только стандартная библиотека. Для вопросов и другой работы в iEWR Python не является общим требованием.

Скопируйте поручение в новый разговор:

```text
Прочитай AGENTS.md и используй его как рабочие инструкции для моей текущей задачи.

Создай и проверь небольшую консольную утилиту проверки сроков коммерческих предложений. Работай самостоятельно в этой папке: выбери подходящий метод, реализуй утилиту, запусти и протестируй её. Используй Python 3 и только стандартную библиотеку; установка пакетов и доступ к сети не нужны.

Пользователь явно задаёт дату проверки параметром --as-of в формате YYYY-MM-DD. Предложение действительно по последний день включительно, просрочено после него и некорректно, если valid_until отсутствует или не является настоящей календарной датой YYYY-MM-DD. Ошибка в одной строке не должна останавливать обработку остальных. Сохрани каждую строку и её id в выходном CSV, добавив столбец status со значением valid, expired или invalid.

Создай project/source/first-experiment/quotes.csv из этих синтетических данных и затем оставь входной файл неизменным:
id,valid_until
Q1,2026-11-04
Q2,2026-11-05
Q3,2026-11-06
Q4,2026-02-30
Q5,
Q6,not-a-date

Сохрани утилиту, тесты, результат для --as-of 2026-11-05 и короткий README в project/artifacts/first-experiment/. Оставь файлы поставки среды неизменными. В итоговом ответе дай одну команду запуска из корня среды, укажи фактически выполненные проверки и оставшиеся ограничения. Это локальный эксперимент; ничего не публикуй.
```

## Проверить результат

Откройте `project/artifacts/first-experiment/`. По README агента повторите запуск утилиты и тестов. Для фиксированной даты **2026-11-05** результат должен содержать все шесть строк:

| id | Ожидаемый status |
|---|---|
| Q1 | expired |
| Q2 | valid |
| Q3 | valid |
| Q4 | invalid |
| Q5 | invalid |
| Q6 | invalid |

Q2 проверяет включение последнего дня. Q4–Q6 должны остаться в результате как invalid: они не должны исчезать или мешать обработке корректных строк. Сверьте исходный CSV с шестью строками поручения. Агент должен сообщить реальные проверки и оставшиеся ограничения. Убедительного объяснения или прохождения собственных тестов агента недостаточно.

Если агент ограничился планом, попросите выполнить и проверить порученное решение. Если запуск заблокирован, установите, какой команды, доступа или средства исполнения не хватает. Результат этого опыта — небольшая локальная демонстрация; пригодность для реальных бизнес-данных оценивается отдельно.

## Перейти к своей задаче {#own-task}

Опишите нужный результат, его ценность, ограничения и границы самостоятельности AI. Поместите материалы в `project/source/`. Поручите агенту выполнить работу, проверить результат и сообщить, что осталось нерешённым.

Основания подхода доступны в [Foundations](/iEWR/ru/foundations/). См. также [устройство iEWR](/iEWR/ru/how-iewr-works/) и [кейс со свидетельствами](/iEWR/ru/cases/). Текущее устройство и ограничения среды — в [README](https://github.com/instantiatio/iEWR/blob/7.0.6/README.md) и [статусе релиза](https://github.com/instantiatio/iEWR/blob/7.0.6/STATUS.md).

## Границы проверки

Отдельно проверены начало с вопроса и продолжение в двух новых CLI-сессиях в чистой папке 7.0.6. Приблизительная идея на английском привела к краткому описанию проекта и записи продолжения, созданной агентом; новая сессия на русском восстановила цель, результат и открытые решения по этим файлам без прежней переписки. Проверены локальный вход и продолжение на том же компьютере и аккаунте.

Один автоматизированный прогон Codex CLI выполнил английское поручение в заново распакованной папке 7.0.6 на macOS с Python 3.14.6. Запуск и тесты повторены отдельно; все шесть строк совпали с ожиданиями. Создание аккаунта, ручной интерактивный запуск, другие агентные среды и ОС, а также отдельный прогон русского поручения не проверялись.
