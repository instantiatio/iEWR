# Первый эксперимент

Небольшое поручение с заранее известными ответами: проверка сроков коммерческих предложений. Сначала [откройте проект iEWR](/iEWR/ru/try/#download). Для этого опыта нужен Python 3; утилита использует стандартную библиотеку. Для других задач Python не является общим требованием iEWR.

## Дать поручение

В этом проверенном опыте AI создаёт утилиту проверки сроков коммерческих предложений. Последний день действия и ошибочные даты позволяют проверить содержательное поведение программы.

Для него нужен Python 3; используется только стандартная библиотека. Для вопросов и другой работы в iEWR Python не является общим требованием.

Скопируйте поручение в новый разговор:

```text
Прочитай AGENTS.md и используй его как рабочие инструкции для моей текущей задачи.

Создай и проверь небольшую консольную утилиту проверки сроков коммерческих предложений. Работай самостоятельно в этой папке: выбери подходящий метод, реализуй утилиту, запусти и протестируй её. Используй Python 3 и только стандартную библиотеку; установка пакетов и доступ к сети не нужны.

Пользователь явно задаёт дату проверки параметром --as-of в формате YYYY-MM-DD. Предложение действительно по последний день включительно, просрочено после него и некорректно, если valid_until отсутствует или не является настоящей календарной датой YYYY-MM-DD. Ошибка в одной строке не должна останавливать обработку остальных. Сохрани каждую строку и её id в выходном CSV, добавив столбец status со значением valid, expired или invalid.

Создай project/source/first-experiment/quotes.csv из этих синтетических данных и затем оставь входной файл неизменным:
id,valid_until
Q1,2026-11-04
Q2,2026-11-05
Q3,2026-11-06
Q4,2026-02-30
Q5,
Q6,not-a-date

Сохрани утилиту, тесты, результат для --as-of 2026-11-05 и короткий README в project/artifacts/first-experiment/. Оставь файлы поставки среды неизменными. В итоговом ответе дай одну команду запуска из корня среды, укажи фактически выполненные проверки и оставшиеся ограничения. Это локальный эксперимент; ничего не публикуй.
```

## Проверить результат

Откройте `project/artifacts/first-experiment/`. По README агента повторите запуск утилиты и тестов. Для фиксированной даты **2026-11-05** результат должен содержать все шесть строк:

| id | Ожидаемый status |
|---|---|
| Q1 | expired |
| Q2 | valid |
| Q3 | valid |
| Q4 | invalid |
| Q5 | invalid |
| Q6 | invalid |

Q2 проверяет включение последнего дня. Q4–Q6 должны остаться в результате как invalid: они не должны исчезать или мешать обработке корректных строк. Сверьте исходный CSV с шестью строками поручения. Агент должен сообщить реальные проверки и оставшиеся ограничения. Убедительного объяснения или прохождения собственных тестов агента недостаточно.

Если агент ограничился планом, попросите выполнить и проверить порученное решение. Если запуск заблокирован, установите, какой команды, доступа или средства исполнения не хватает. Результат этого опыта — небольшая локальная демонстрация; пригодность для реальных бизнес-данных оценивается отдельно.
