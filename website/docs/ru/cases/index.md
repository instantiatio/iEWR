## От бизнес-правила к проверенной утилите

**Задача:** создать консольную утилиту проверки сроков коммерческих предложений. Предложение действительно по последний день включительно. Пропущенные или невозможные даты нужно отмечать как некорректные, сохраняя строки и продолжая обработку файла.

Человек задал цель, CSV-данные, условия приёмки и границы исполнения. В заново распакованной папке iEWR 7.0.6 новый сеанс агента самостоятельно выбрал подход, реализовал утилиту, написал тесты, запустил решение и подготовил README. По ходу прогона человек не корректировал содержание решения и не давал указаний по реализации.

### Результат

Агент подготовил программу на стандартной библиотеке Python, пять исполняемых тестов, обработанный CSV и инструкцию запуска. Исходный файл и все 42 файла поставки iEWR сохранены.

Для явно заданной даты проверки **2026-11-05** получен результат:

| id | valid_until | status |
|---|---|---|
| Q1 | 2026-11-04 | expired |
| Q2 | 2026-11-05 | valid |
| Q3 | 2026-11-06 | valid |
| Q4 | 2026-02-30 | invalid |
| Q5 | пусто | invalid |
| Q6 | not-a-date | invalid |

### Проверки

Ожидаемые ответы зафиксированы до исполнения. Отдельная проверка повторила документированную команду и все пять тестов, сопоставила каждую строку с ожиданиями и проверила сохранность входа и файлов поставки.

При смене даты проверки на 2026-11-06 Q2 стал expired, а Q3 остался valid. Средство сопоставления также испытали на трёх ошибочных результатах: исключённом последнем дне, потерянных некорректных строках и объявлении всех строк действительными. Оно отклонило все три.

### Повторить или изучить

Чтобы AI создал решение, следуйте маршруту [«Попробовать iEWR»](/iEWR/ru/try/) с новой копией среды и подготовленным поручением.

Чтобы изучить готовое решение, [скачайте комплект свидетельств](/iEWR/assets/quotation-expiry.zip) и распакуйте в отдельную папку. Из этой папки выполните:

```sh
python3 project/artifacts/first-experiment/check_quotes.py project/source/first-experiment/quotes.csv project/artifacts/first-experiment/output.csv --as-of 2026-11-05
python3 -m unittest discover -s project/artifacts/first-experiment -v
```

Комплект содержит программу, тесты, вход, ожидаемый выход и сохранённые проверки. Так запускается уже полученная утилита; её создание агентом — эксперимент из Try iEWR.

### Условия прогона

Использовались iEWR 7.0.6, Codex CLI 0.166.0-alpha.6, macOS 27.0.1 arm64 и Python 3.14.6. Выполнено английское поручение; русское представляет соответствующую локализацию. Точный снимок серверной модели не зафиксирован. Агент использовал существующий аккаунт с выполненным входом на том же компьютере, где проводилась проверка.

Программа обрабатывает UTF-8 CSV в памяти и записывает выход напрямую. Большие файлы, конкурентная запись и прерывание записи не входили в этот опыт. Условия формата входа указаны в README утилиты.

Результат показывает завершённое небольшое поручение: выбор метода, реализацию бизнес-правила, обработку границ и неверных данных, выполнение проверок и передачу пригодных для повторного использования файлов.
