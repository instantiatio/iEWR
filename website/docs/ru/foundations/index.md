# Основания

Здесь собраны идеи Instantiatio и iEWR для углублённого изучения. Можно сразу перейти к [практическому запуску](/iEWR/ru/try/) и обращаться к этим материалам по возникающим вопросам.

- [Instantiatio](/iEWR/ru/foundations/instantiatio/) — воплощение намерения в работающий результат через модели, деятельность и проверку.
- [Девять принципов AI-native-first](/iEWR/ru/foundations/ai-native-first/) — цели, ценность, субъектность, самостоятельное исполнение и обратная связь.
- [System Formation](/iEWR/ru/foundations/system-formation/) — как назначение и состояние системы определяют необходимую работу.
- [Engineering Work Runtime](/iEWR/ru/foundations/ewr/) — среда организации, исполнения, проверки и продолжения деятельности.
- [FPF, Dynamic Method Generation и MethodPack](/iEWR/ru/foundations/methods/) — получение методов и сохранение полезного опыта.

Конкретная конфигурация 7.0.6 описана в разделе [«Как устроена iEWR»](/iEWR/ru/how-iewr-works/).
