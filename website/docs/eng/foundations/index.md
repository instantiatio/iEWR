# Foundations

The ideas behind Instantiatio and iEWR are available here for deeper reading. You can go directly to [Try iEWR](/iEWR/eng/try/) and return to these materials as questions arise.

- [Instantiatio](/iEWR/eng/foundations/instantiatio/) — how intent becomes a working result through models, activity, and checking.
- [Nine AI-native-first principles](/iEWR/eng/foundations/ai-native-first/) — goals, value, human agency, independent execution, and feedback.
- [System Formation](/iEWR/eng/foundations/system-formation/) — how the system's purpose and state determine the necessary work.
- [Engineering Work Runtime](/iEWR/eng/foundations/ewr/) — the environment supporting organization, execution, checking, and continuation.
- [FPF, Dynamic Method Generation, and MethodPack](/iEWR/eng/foundations/methods/) — obtaining methods and preserving useful experience.
