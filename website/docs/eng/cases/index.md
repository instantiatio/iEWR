# Cases & Experiments

The task, the work performed, the result, and its checks make an experiment useful to others. The materials below connect assignments to results, checks, and conditions.

## GEO CRM: one project across agent environments

From a local CRM assignment to sales, stock, expense requests, and liquidity modelling in one application. Development continued through **Codex → DeepSeek Harness → Codex**; the saved context also supported two finance guides. The current 1.4.0-demo report records 36 tests, a connected business scenario, and an independent cash-flow calculation.

[Read the GEO CRM case and view the screenshots](/iEWR/eng/cases/geo-crm/).

## From a business rule to a checked tool

A short assignment to check sales quotation expiry dates. In a fresh iEWR 7.0.6 workspace, the agent independently produced a program, five tests, a processed CSV, and run instructions. Checks covered the final valid day, invalid dates, and preservation of input files.

[Read the case and inspect the checks](/iEWR/eng/cases/quotation-expiry/).
