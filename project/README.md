# Материалы проекта

Начать можно с диалога. Создавайте материалы и дополнительную структуру, когда они нужны результату, передаче или продолжению.

- `source/` — входящие оригиналы; не перезаписывайте их преобразованиями.
- `artifacts/` — результаты и необходимые основания; `process/` используется только для нужной устойчивой истории.
- `handoff/` — материалы для передачи между участниками проекта: людьми и ИИ-агентами. Обязательных HTML-форм нет.
- `dpf/` — необязательное место навигации проектного репертуара; его отсутствие не требует создания.

Рабочий документ можно править на месте с сохранением пользовательских изменений. Зафиксированную редакцию исправляйте новой редакцией; прежнюю сохраняйте вместе с её основаниями. Оригиналы, существенные решения и использованные результаты не имеют автоматического срока удаления. До опоры на редакцию обеспечьте её сохранность и доступность следующему участнику.

Существенное решение сохраняйте точными словами с предметом, редакцией и условиями. Рекомендация, ответ, интерпретация и действие различаются. Для продолжения достаточно имеющейся истории, если из неё восстанавливаются прямые основания, relied basis и факты; обязательных JSON records и общего журнала нет. Достаточно сохранённый ответ не запрашивается повторно.

Входящие источники, reference и frameworks read-only без отдельного точного поручения. Хеш, имя current и время файла не заменяют происхождение или разрешение. До записи установите актуальную редакцию и достаточную очередность/контроль конфликта; после неизвестного эффекта сначала сверяйте выполненное. Полные правила — в [AGENTS](../AGENTS.md).
