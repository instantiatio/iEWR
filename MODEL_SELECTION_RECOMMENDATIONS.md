# Выбор исполнителя и tool configuration

Текущая guidance: [I](modules/interaction/HUMAN_INTERACTION.md) объясняет выбор;
[P](adapters/ADAPTERS.md) сообщает observed capability/configuration; G проверяет
независимые relations, X использует current bound basis. Это optional advice,
не router policy, обязательная стадия, provider rank или authority.

Под named question/use сравнивать actual supported tools, task evidence,
limitations, available budget, latency и data/effect boundary. Model name,
family, context size, tool access или confidence не доказывают competence,
independence или assignment. Независимость review устанавливается по нужному
claim, Method и actual participants/evidence; другая марка сама её не обеспечивает.

Если current configuration достаточна, продолжить без model interview. При
недостатке basis назвать affected capability/result и выбрать разрешённый bounded
fallback, source/result request либо stop. Нельзя запускать delegation, платить
за provider, передавать данные или менять host configuration из рекомендации.
Changed model/host требует нужного R re-entry и current bindings; successful
output не создаёт полномочий или blanket reliance.

Прежние датированные списки моделей, цены и автоматические этапные назначения
retired из active advice. Их old bytes сохранены в local B7 old/new evidence и
frozen reference; они читаются только как historical claims, без обновления
или внешнего исследования в этой фазе. При новом actual procurement/use exact
технические и стоимостные основания потребуют своей проверки в его scope.
