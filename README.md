# iEWR 7.0.0 Eternal Alpha

iEWR — исследовательская инженерная среда для совместной работы человека и AI. Вы задаёте, какой результат нужен, зачем и в каких пределах агент действует самостоятельно. Агент помогает сформировать работу, подобрать способы, выполнить порученное и проверить результат.

**Eternal Alpha** обозначает исследовательский характер среды: её устройство и методы развиваются по результатам применения. Пригодность конкретного результата проверяется для его использования.

## Начало работы

1. Распакуйте архив и откройте папку `iEWR` в агентской среде, которая умеет читать и изменять файлы и выполнять необходимые задаче действия.
2. Дайте агенту прочитать [AGENTS.md](AGENTS.md), если среда не подключает этот файл автоматически. Готовый текст начала — [START.txt](START.txt).
3. Опишите задачу, нужный результат и существенные ограничения. Материалы можно положить в `project/source/` либо указать уже существующий рабочий контекст.
4. Результаты сохраняются в `project/artifacts/`, а материалы для передачи и продолжения между людьми и агентами — в `project/handoff/`.

Например: «Изучи материалы в project/source/, предложи решение и обсуди со мной существенные варианты» — совместная работа S3. Или: «Подготовь и проверь решение самостоятельно в этих пределах» — делегирование S4. Новому проекту не требуется заранее создавать CURRENT.json или универсальный комплект документов.

## Методологическая основа

Рабочая связка — **Инструкции + FPF + MethodPack**. FPF (First Principles Framework) Анатолия Левенчука предоставляет общую методологию; точный оригинал включён в комплект. MethodPack — прикладной репертуар: одна тематическая книга и YAML-индекс с 37 описаниями методов. При новом выборе агент сначала проверяет достаточный вклад FPF, затем нужную конкретику MethodPack и развивает недостающее под задачу.

Этот механизм называется **Dynamic Method Generation (DMG)**. Он охватывает поиск, переиспользование, адаптацию и создание способов. Повторно полезные методы накапливаются с основаниями, связями, проверками и сохранёнными редакциями. Полный обход FPF и применение всего репертуара не требуются.

Можно поручать методы напрямую: «Примени TEXT-EDIT из MethodPack к этому тексту». [Карта файлов](docs/FILES.md), [каталог методов](docs/METHODS.md), [краткое описание архитектуры и mini ConOps](docs/MINI_CONOPS.md), [полный ConOps](docs/IEWR_CONOPS.md).

## Развитие и проверки

Агент может по поручению [развивать саму среду](docs/SELF_DEVELOPMENT.md) и [создавать DPF](docs/DPF_CREATION.md) по каноническому методу FPF. Новая редакция MethodPack подключается через [поставленный контроль](docs/METHODPACK_CHECK.md); агент выполняет команды в пределах вашего поручения.

Начальная проверка репертуара из корня папки:

```sh
python3 -B tools/methodpack.py check --json
```

Для этих утилит нужен Python 3.10 или новее. Поставленный YAML-индекс читается стандартной библиотекой; иной YAML требует доступного PyYAML. Подключение и восстановление пары через helper используют POSIX flock; проверены на macOS. Возможности инструментов и доступы задаёт выбранная агентская среда. [Область проверок](STATUS.md), [изменения версии](RELEASE_NOTES.md).

Для нового проекта папка уже подготовлена. При обновлении существующего проекта сохраните его исходники, методы, решения и незавершённую работу; [порядок переноса](docs/NEW_PROJECT.md).
