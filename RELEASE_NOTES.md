# iEWR 5.8.1 Beta

Обновлены два собственных DPF. WEP 0.1.5 помогает выбрать глубину проверки текста: для обычной правки достаточно самопроверки, а существенный вопрос, который исполнитель не может разрешить, требует отдельной предметной оценки. VID 0.3.0 уточняет компактные элементы управления, доступные имена и состояния, загрузку шрифтов и изображений, прерывание и повтор переходов. Окончательный эстетический выбор остаётся у человека; AI самостоятельно выполняет порученную техническую работу. Если достаточное направление уже задано, новый вкусовой выбор не нужен.

Состав не расширен: 17 DPF и 278 методов. Остальные пятнадцать источников, Core и программные механизмы сохранены. README и эта заметка отредактированы по WEP: пояснения стали прямее, условия и ограничения сохранены. Для перехода сохраните прежнюю поставку, распакуйте новую отдельно и проверьте перенос материалов и оснований проекта. Начатая работа не переключается на новые редакции автоматически; оригинальный FPF в поставку не входит.

Интеграция, ссылки, контрольные суммы и чистая распаковка проверяются перед публикацией; фактические результаты приведены в [VERIFICATION.md](VERIFICATION.md). Положительные AI-оценки авторских файлов не заменяют проверку конкретного результата. Сравнительное преимущество VID не установлено; влияние обновления на понимание читателя и затраты времени не измерялось. Выпуск подготовлен для прямо порученной публикации как Latest с обновлением главной. [История выпусков](RELEASE_HISTORY.md).
