# iEWR 7.0.0 Eternal Alpha

Обновлённый предварительный исследовательский выпуск, сборка `release-r2`. Техническая метка — `7.0.0-release-r2`; прежний выпуск `7.0.0` и его файлы сохранены. Главная ветка и Latest остаются на 6.0.8.

В комплект вошли проверенные уточнения среды: стандартное приветствие, русская редактура 37 методов и каталог METHOD_CATALOG, согласование текущего состояния и истории по KCA-04/05, состав снимков и экспорта по KCA-01, единая исходная пара MP base-v3.10. История разработки и проектные данные в чистый ZIP не включены.

Текущая работа iEWR и развитие MP не требуют обязательного Python при достаточных средствах ADE. Подходящий готовый Python helper переиспользуется; ограниченный файловый путь одного агента сохраняет проверки, before/after и журнал восстановления. Отказ по повреждённым входам нельзя обходить сменой реализации. Параллельная произвольная запись и отказ питания не квалифицированы.

Смена редакции FPF по поручению выполняется готовым согласованным комплектом оригинала и структурного индекса с происхождением, условиями и достаточной проверкой. Локальная генерация не является условием повседневной работы; поставленный генератор использует Python при подготовке/обслуживании. В этом выпуске сам FPF и его индекс не менялись.

Скачайте ZIP и откройте папку `iEWR-7.0.0-Eternal-Alpha`. Начало — README.md и AGENTS.md. Для обновления существующего проекта сначала сохраните его материалы и изменения; порядок — docs/NEW_PROJECT.md и SELF_DEVELOPMENT.md. Состав — docs/FILES.md и INSTALLATION.json; пределы — STATUS.md и PORTABILITY.md.
