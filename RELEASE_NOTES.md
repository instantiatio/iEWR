# iEWR 7.0.3 Eternal Alpha

Выпуск подготовлен 04.11.2026 на основе рабочей 7.0.2 с локальными доработками документации.

Описание iEWR, начало работы и перенос проекта — в [README.md](README.md).

## Что изменилось

- ConOps дополнен пользователем и ситуациями использования, взаимодействием команд, вопросами оценки успешности и порядком изменения концепции.
- Связно раскрыты System Formation, инженерный контекст, перестройка работы, выбор технической защиты и допустимой компенсации. Проведена редактура по WEP; шапка отделена от тела документа.
- README доработан по замечаниям Human: добавлены назначение и примеры проектов, ссылки с пояснениями, порядок переноса через путь к проекту, папку или ZIP. Убраны лишние технические подробности и внутренние обозначения; пояснён DPF.
- Отдельный NEW_PROJECT.md убран; действующие ссылки и адрес инструкции переноса направлены в README.
- Закреплено правило: при смене версии без отдельного пожелания Human в README меняются только действительно изменившиеся числовые значения. Новое описывается в release notes со ссылкой на README, без дублирования начала работы и реквизитов.
- Папка внутри ZIP — `iEWR-7.0.3-Eternal Alpha`. Лишние обозначения редакций новой сборки убраны. Проектные папки пусты; рабочая история в комплект не включена.

FPF, MethodPack base-v3.10 с 37 описаниями и исходным снимком, инструменты и лицензионные материалы сохранены без изменения. Семь функций и их связи сохранены.

## Что проверено

Проверены состав и контрольные суммы извлечённого ZIP, местные ссылки и якоря, карта файлов, согласованность MethodPack и структурного индекса FPF, сохранность исходной основы и согласованного описания README. В ConOps при подготовке 7.0.3 изменена только шапка.

Прежние ограниченные агентские пробы не переатрибутируются новой редакции. Новый модельный самоаудит на чистом проекте не проводился; зафиксированные пробелы ConOps остаются отложенными. Область проверенности — [STATUS.md](STATUS.md).
