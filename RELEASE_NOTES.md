# iEWR 7.0.0 Eternal Alpha

Предварительный исследовательский выпуск: самостоятельный чистый комплект среды. Начало — README.md и AGENTS.md; START.txt содержит только короткое обращение к инструкциям.

Включены точный FPF со структурным индексом, 37 прикладных методов с YAML-индексом, одна исходная пара MP base-v3.4, ConOps и mini ConOps, каталог методов, docs/FILES.md, входы в саморазвитие/создание DPF и инструменты check/activate/recover. Папки проекта пусты.

Методы сохраняют свои операционные действия, условия и проверки. Описания самостоятельны: источники и действующие FPF-связи доступны непосредственно из книги, индекса и сведений об авторстве. Предметные решения и фактический опыт накапливаются по работе проекта.

Для другого нового проекта распакуйте исходный ZIP в пустой каталог. Существующий проект переносится с сохранением его материалов, методов, решений и продолжения; архив не накладывается поверх рабочей папки вслепую. Средства и пределы проверок — STATUS.md.

## Исходный проект и обновление

В PACKAGE.json закреплены собственный репозиторий iEWR, публичная опора исходной линии и точная непосредственная основа этой сборки. Вход саморазвития использует эти сведения для сравнения и обновления с сохранением проектных изменений. README содержит ссылки на iEWR, опубликованные выпуски, сайт автора FPF и авторский репозиторий FPF. Исследовательский статус и условия источников сохранены.

Выпуск 7.0.0 опубликован отдельно как prerelease. Главная ветка и Latest сохранены на 6.0.8. Для начала работы используйте приложенный ZIP с подготовленными папками проекта.
