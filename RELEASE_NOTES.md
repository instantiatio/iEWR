# iEWR 5.6.1 Beta

В базовой поставке прежний SDLC DPF заменён на **Instantiatio SDLC DPF 0.2.2**. Вместо четырёх методов работы с кодом доступны 18 методов: требования и качество, архитектура, данные и SQL, API и повторы, UI/UX, клиентское состояние, безопасность, выбор компонентов, согласование изменений, проверка, выпуск и сопровождение. Активный состав сохраняет 14 DPF и теперь содержит 242 метода.

Новые методы выбираются по задаче через существующий каталог. Ядро и исполняемые инструменты iEWR не изменены; FPF по-прежнему подключается только по намерению пользователя. Для перехода распакуйте новую версию отдельно и сохраните материалы проекта. Старые SDLC.1–4 остаются историческими адресами; соответствующие новые методы ISDLC.15–18 не перенаправляют прежние привязки автоматически.

Источник сохраняет авторский статус кандидата для ограниченной проектной пробы. Проверки целостности, состава, ссылок и ограниченного применения описаны в [VERIFICATION.md](VERIFICATION.md); они не означают промышленной пригодности всех методов или общей квалификации агента. Исходные тексты, атрибуция и история сохранены. [История выпусков](RELEASE_HISTORY.md) доступна отдельно.
