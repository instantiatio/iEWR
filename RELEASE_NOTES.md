# iEWR 6.0.0

6.0.0 — переход к новой архитектуре iEWR: способы работы задаются DPF, а выполнение обеспечивает выбранная агентская среда.

## Что изменилось

- Основные инструкции собраны в одном AGENTS.md. Работу можно начать с описания задачи; план и дополнительные документы создаются по необходимости.
- Базовый комплект содержит 15 DPF. Дополнительные методы подключаются по вашему поручению или после согласования.
- Представление результатов выбирается по задаче: достаточно подходящего текста, таблицы или другого удобного формата.
- Для обычной работы больше не нужен отдельный программный исполнитель iEWR: действия выполняет выбранная агентская среда.
- Уточнены правила продолжения работы после прерывания и согласования изменения результата.

## При переходе с 5.x

Прежние программные интеграции требуют адаптации. Перед переходом сохраните материалы проекта и используемые методы. Подробности — в [руководстве по переходу](docs/MIGRATION_6_0.md).

[Как начать работу](README.md#как-начать).
