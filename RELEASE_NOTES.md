# Изменения iEWR 5.5.6 Beta

В инструкциях явно описана активная помощь человеку, который пока не может
сформулировать нужный результат. Агент использует контекст, предлагает
различающиеся варианты и примеры, при необходимости — небольшую обратимую пробу
в разрешённых границах. Ответы и коррекции меняют следующий ход; ясная задача
выполняется без обязательного интервью. Цели, существенные компромиссы и
разрешения остаются за человеком. Дополнительно разделены формирование задачи,
подготовка выполнения и фактический результат. Перед ближайшим действием
устанавливаются достаточные условия его выполнения и проверки; пробы могут
уточнять постановку. Обязательные стадии и повторные согласования не вводятся.

Новые Decision View возвращают ответ через исходный чат: выбрать вариант или
написать ответ, нажать «Скопировать ответ для чата», вставить и отправить сообщение.
При отказе автоматического копирования доступен готовый текст для ручного
копирования. Форма остаётся редактируемой и сообщает об устаревшей копии.
Старые вопросы и HTML-ответы сохраняются; прежний способ их чтения доступен.
Получение, интерпретация и действия учитываются отдельно; повтор ответа через
разные каналы не повторяет действий, изменение решения требует явного разбора.

Механизм Decision View проверен на рабочей редакции, чьи программные файлы
включены без изменений: 16 проверок в изолированном Chrome и 17 проверок
чтения/фиксации ответов.
Реальное копирование и вставка проверены на локальной странице; отказ API и
гонки воспроизведены управляемыми подстановками. Эти наблюдения не подтверждают
работу Clipboard API во всех встроенных браузерах. Сравнительные пробы агентов
и анализ ситуаций ограничены выбранными примерами; общее улучшение поведения
и снижение нагрузки на человека не доказаны. Дополнительная проба новых
инструкций охватила четыре последовательных хода без переписки разработки;
проверены состав, контрольные суммы и зависимости. Подробные пределы указаны в
[статусе конфигурации](BASELINE_STATUS.md).

Версия iEWR 5.5.6 Beta и публикация как Latest разрешены прямым поручением
пользователя. Статусы внутри ZIP относятся к моменту фиксации перед публикацией;
её факт отражает [страница выпуска](https://github.com/instantiatio/iEWR/releases/tag/5.5.6-beta).
При переходе распакуйте ZIP в новый каталог, сохранив прежние материалы проекта.
История прежних выпусков сохранена в
[истории](RELEASE_HISTORY.md). Core, полномочия, исходные DPF и архив baseline
не изменены.
