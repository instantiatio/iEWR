# Собственные DPF Instantiatio в iEWR 6.0.2 Beta

Автор Albert прямо поручил обновление выбранных DPF, проверку, публичный выпуск iEWR 6.0.2 Beta как Latest и обновление main. WEP 0.1.6 получен из приватного `instantiatio/dpf-lab` через локальную авторизацию GitHub CLI; подключение GitHub API не имело доступа. Приватность исходного репозитория не отменяет этого прямого разрешения на включение выбранного текста.

WEP сохраняет все 12 методов. Все 24 раздела Solution и Archetypal Grounding совпали с поставкой 0.1.5 побайтно. Изменены объяснения и навигация; Preface стал «Архитектурной справкой». В поставке адаптированы только назначения относительных Markdown-ссылок на точные авторские URLs. Источники WED/HUM и материалы разработки остаются внешними: доступ к приватному репозиторию нужен отдельно; они не включены в комплект и не требуются для каждого обычного применения WEP.

Отдельная общая лицензия на эти DPF не установлена: MIT iEWR и CC BY 4.0 других авторов не переносятся автоматически. Сторонние материалы сохраняют notices.
