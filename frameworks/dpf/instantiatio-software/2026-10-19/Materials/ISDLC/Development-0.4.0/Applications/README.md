# Локальные применения связей ISDLC, DDB и SVV

[join_probes.py](https://github.com/instantiatio/dpf-lab/blob/fe1267ac7d84196342408e1367f912ff8fe95810/Materials/ISDLC/Development-0.4.0/Applications/join_probes.py) и [наблюдения](RESULTS.json) изготовлены при разработке ISDLC 0.4.0. Шесть авторских проб выполнены Python 3 со стандартной библиотекой; точные версии и hashes находятся в результате. Используется существующая [SQLite-модель](https://github.com/instantiatio/dpf-lab/blob/fe1267ac7d84196342408e1367f912ff8fe95810/Materials/Software-DPF/Trials/trial_application.py), без её изменения и копирования.

Это явные авторские применения прочитанных способов: задача и выбранный oracle заданы автором, код представляет ограниченную реализацию для наблюдения. Скрипт не исполняет произвольный текст DPF и не доказывает качество всех 18 методов. Независимое AI-чтение текста сохранено отдельно от этих проб.

## Повторение

Из корня репозитория:

```sh
python3 Materials/ISDLC/Development-0.4.0/Applications/join_probes.py /tmp/isdlc-new-observation.json
```

Путь результата должен быть новым: сохранённые наблюдения не заменяются. Для воспроизведения нужны исходник и относительное расположение общей fixture в этом репозитории. Временные БД и файл намерения создаются и удаляются внутри пробы.

## Пределы и исправление 0.4.1

Наблюдались SQLite, один процесс с закрытием/открытием соединения, реальный JSON decoder и модель клиентского намерения в файле. Browser/UI, HTTP-сервер, сеть, выключение машины, внешний платёж и промышленная нагрузка не испытывались. Полнота выбранной дельты обеспечена только устройством этой fixture; журнал реальной системы требует собственного основания. Пригодность задачи вJ4 — заданный контрпример, человеческого наблюдения не было.

В 0.4.1 изменены номера редакции, указатели и уведомление об историческом источнике в.17:11; действия, контракты и ожидания всех шести проб остались теми же. Поэтому сохранённые наблюдения 0.4.0 переиспользованы с этой установленной границей влияния. Новый запуск и новое холодное чтение при этом не заявляются.
