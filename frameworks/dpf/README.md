# Хранение DPF

Полный выбранный текст расположен в `<код>/<редакция>/<код>.md`. Номер редакции принадлежит DPF; номер выпуска iEWR в путь DPF не входит. Один выбранный экземпляр каждого кода зарегистрирован в [репертуаре](REPERTOIRE.yaml). Базовый или дополнительный статус задаётся регистрацией, а не отдельным деревом каталогов.

[Указатель методов](../../catalog/dpf/METHODS.md) ведёт прямо к полному телу. [Происхождение и обратимые изменения ссылок](SOURCES.json) сохраняют исходные и поставочные bytes отдельно. Сопровождение и сохранённые оценки — в [docs/dpf](../../docs/dpf/README.md). Старые редакции остаются в прежних выпусках и истории проекта; их наличие в истории не выбирает их для новой работы.

Оригинальный FPF в поставку не входит. Авторство и лицензии — в [NOTICE](NOTICE.md), [LICENSE](LICENSE) и [LICENSING](LICENSING.md).
