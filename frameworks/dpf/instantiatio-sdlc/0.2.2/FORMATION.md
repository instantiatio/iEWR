# Формирование переносимой редакции 0.2.2

## Поручение и основания

Human поручил сделать ZIP для помещения в source проекта доработки iEWR. Основание содержания — exact [0.2.1](../0.2.1/DPF.md) и [полное ревью Astra](../reviews/0.2.1-astra-full/REVIEW.md). Передача формируется для этого использования; текущая комплектация iEWR, registration и distribution status не изменяются.

Переиспользованы ME.12:4 для локального исправления и повторной проверки, ME.21/ME.23 для сохранения достаточного метода без расширения словаря, SYSE.14:4 для передачи определённой конфигурации под определённое использование. Прежняя архитектура и выбранные положения FPF сохраняются. Полный FPF, новые предметные исследования и runtime не добавлены.

## Точная дельта

В ISDLC.16:5 фраза «отсутствующая редакция» могла означать и отсутствие optional аргумента, и заданную редакцию без строк. Теперь явно указано: без edition возвращаются обе строки в прежнем порядке; edition=2 возвращает вторую; заданное несуществующее значение даёт пустой результат. Это уточнение примера, число 18 и IDs сохранены; остальные 17 тел не изменены.

В сопровождении обновлены edition/status/history, добавлены переносимые указатели внешних оригиналов и точная атрибуция. Текущие локальные ссылки доступны в архиве; исторические документы и ревью оставлены exact, включая прежние workspace references. Прежние редакции не переписаны. Полное независимое ревью относится к 0.2.1; авторская проверка новой дельты и архивирования указана в [VERIFICATION.md](VERIFICATION.md).

## Фактические эффекты

Созданы новая проектная редакция и переносимый ZIP с исходами проверки. В целевой проект ничего не записано, текущий iEWR не установлен и не опубликован. Архив предназначен для входных материалов будущего поручения. Автоматическое выполнение reviewer probes, загрузка FPF и новые agent functions не включены.
